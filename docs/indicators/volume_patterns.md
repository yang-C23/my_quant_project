## 一、倍量柱体系（无现成 TDX 公式，按笔记规则量化）

### 定义（笔记原文）

> "某一交易日的成交量，是前一个交易日的2倍及以上，这根成交量柱就是'倍量柱'。"（宽松口径：2.5倍、3倍、10倍都叫倍量）

> 第一性原则："下跌是不需要看量的。放量下跌和缩量下跌，本质都是真实的下跌。" 只有**上升途中的放量**（真金白银买上去）与**回调段的缩量**才有信息。

### 量的三类

| 类型 | 定义 | 含义 |
|---|---|---|
| 一般放量 | +30~50% | 无意义 |
| **倍量** | ≥2× 昨量 | 大哥进场（主力真实买入） |
| 天量 | 倍量再倍量 / 连续巨量 | 加速赶顶，准备离场 |

### 主力控盘脚印（输出布尔列）

| 形态 | 规则 | 输出列 |
|---|---|---|
| 倍量阳 | `volume ≥ 2×prev AND close>open`（PLRY 的宽松版） | `sig_double_vol_yang` |
| 天王盖地虎 | 倍量阳 → 缩量回调 2–3 天 → 再倍量阳 | `sig_dvy_sandwich` |
| 三门重炮 | 连续 3 天倍量柱且量价齐升（最强买点） | `sig_triple_dvy` |
| 缩量半量下跌 | 前一日非实体阴 AND 跌 AND `volume ≤ 0.5×prev`（同 B1 的 HALF_DOWN） | `sig_half_down` |
| 地量 | `volume ≤ LLV(volume, 60) × 1.1` 附近（洗盘末端，异动后的买点） | `sig_dead_vol` |
| 高位倍量阴 | 高位 + 倍量 + 实体阴 = 出货，回避 | `sig_dvy_distribution` |

纪律（策略层）：**永不追倍量柱当根**，进自选等回调 B1；缩量上涨=虚假繁荣（对倒），只有量价齐升健康。
异动（2025-08-13）：突然放量、价随量升、发生在 60 日线附近/之下才有效；买点不是异动本身而是其后的**地量**。

### "算面积"震仓判别（研究级，可后置）

比较下跌段绿柱累计面积 vs 前升段红柱面积：绿面积远小于红面积但价格跌得深 → 震仓（白线未破则持有/加仓）。实现为 `washout_area_ratio(df, window)` 返回连续值，不强做布尔。

## 二、单针下20（深V战法）——**代理版**

原始定义依赖**指南针"知行洗盘指标"**：红线（机构资金线）≥80 且白线（散户资金线）≤20 → "单针下二十"。该资金线为指南针专有算法，**无公开公式，不可精确复刻**。

处置：
1. 实现**形态代理版**并明确命名 `single_needle_proxy`：上升趋势/横盘（白线>黄线或 BBI 之上）AND 当日长下影深V（下影 ≥ 实体×2 且盘中最大跌幅 ≥3% 后收回）AND **缩量 ≤ 0.5×昨量** AND N 型低点未破。
2. 笔记中的先验统计（原文）："胜率约 37%，盈亏比 3:1——单次盈利多为 4%-6%，亏损控制在 2% 以内"。回测时以此为对照预期。
3. 操作纪律（策略层）：持有 1 日，未脱离成本次日开盘走；盈利 ≥3% 放飞一半；高开 >1% 不追；止损 2–3%。
4. 若后期能从指南针抓取资金线数据（用户计划中有 GUI 抓取方案），再立卡实现精确版。

## 移植要点

- 全部规则只用 OHLCV，无未来函数陷阱注意：`sig_dvy_sandwich` / `sig_triple_dvy` 的"回调2–3天后再倍量"以**最后一根倍量阳当日**为信号日。
- 阈值（2.0/0.5/60 等）全部参数化进函数签名默认值。
