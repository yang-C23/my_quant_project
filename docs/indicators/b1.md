## B1/B2/B3 理论（策略层与止损规则）

- **B1** = 阶段性低点，唯一判据 J<13（任意周期）。止损：买入 K 线最低价 / 3–5 个价位 / N 型低点（约 3 个点内）。持有规则：3 个交易日内须重新走强或至少企稳。
- **B2** = B1 后 3 日内放量**中阳线**确认（J 拐头向上）。止损：前 N 型低点（约 5%）。持有规则：**2 个交易日内必须拉升**，否则卖出。
- **B3** = B2 后中继**小阳线**。止损：B3 最低价或 B2 大阳实体中价（约 3–4%）。
- 排序：盈亏比 B1>B2>B3；**上涨确定性 B3>B2>B1**（反直觉，重点强调）；止损幅度 B2>B3>B1。
- "三件套"：B1→B2→B3 须在约 3 日内依次出现，否则形态作废。
- 周线/月线级"勾大负值"（J 大负数）= 极端恐慌的中长线吸筹 B1。

## 移植要点

1. `CAPITAL` → `float_shares`（见 indicators/README 映射）；MVOK 移到 universe/signals 层做（指标层不碰市值数据）。
2. `VOL*REAL_YANG` 中布尔按 0/1 参与乘法——直译即可。
3. `HMSHORTWL:=SMA(SMA(C,40,4),100,50)` 是**双层 TDX 递归 SMA**，必须用 TASK-020 的递归实现，warmup 长（>160 根，与 HMLONGYL 的 MA160 一致），前段 NaN。
4. 参数每 1–2 周更新 → `B1Params` 必须可从 `configs/*.yaml` 覆盖；三个预设注册名：`b1_v242_62`（默认）、`b1_v242b`、`b1_v242p`。
5. 板块剔除（原式在通达信选股器里另行设置）统一走 universe。
