# 工程约定

共同契约为根目录`AGENTS.md`；从`docs/ONBOARDING.md`接手。本页只保留工程约束，
金融定义统一引用[数据契约](data_platform.md)和[研究协议](restart/RESEARCH_PROTOCOL.md)。

- Python ≥3.10，当前依赖锁针对3.10；src布局，包名`quant`，安装名`my-quant`。
- 使用工作树独立`.venv`及`scripts/quant`；doctor校验真实导入路径和锁定依赖。
- 公共接口有类型和docstring；logging记录运行状态；CLI通过Typer输出。
- Ruff格式和静态检查；路径来自Settings，src中不写本机绝对路径。
- 大数据按证券/分区批量处理；现金账本和递归指标允许保持顺序的状态循环。
- 发布前拒绝文件解析失败、关键字段变化和未解释异常；异常隔离并保留原值。
- 缺失不填零；数据类型、单位、币种和交易所显式记录。原始/标准/研究层分开。
- 证券标识保留原发布者代码与市场。旧CN兼容层采用`sh600000`等，Qlib映射单独处理；
  公共来源保留`SP500`/`SPY`等原代码，market不可省略。跨市场不能仅凭裸代码合并。
- 日期为本地交易日，发布时间和采集时间为UTC。标准公开数据Parquet使用date32与UTC微秒时间戳；
  TDX兼容staging沿用旧内部datetime列，查询时转交易日，正式标准源不能省略schema验收。
- 研究原价+现金公司行动与复权代理分开，禁止一律套复权价或股票费率。详见权威协议。
- `tests/unit`允许tmp_path小文件与确定性模拟，不联网、不读取真实账户；
  真实快照更新、公开采集及完整恢复由显式CLI验收。
- 先检验关键金融语义和故障行为，再做必要回归；小型独立手算比复制实现的测试更有价值。
- 不提交数据、账户秘密、虚拟环境和缓存。用户数据、其他工作树及旧结果均保留。
- 历史ADR保持原文，新决定通过ADR注明替代关系；结论、公式与任务状态各保留一份权威正文。
