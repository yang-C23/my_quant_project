# R1 — 指标优化研究计划（z哥指标族）

> 状态：active（2026-07-07 立项）｜规划者：Claude｜执行：Codex（研究卡）+ 审查者（OOS 裁定）
> 目标：在**不引入前视偏差、不过拟合**的前提下，评估并优化 docs/indicators/ 指标族；一切结论一条命令可复现。

## 1. 评估协议（硬性，违反=打回）

- **Tier1 事件研究**（`myquant study` / `run_event_study`）：t 信号 → t+1 开盘入场，`entry_filters=ashare`（剔一字板/停牌），`ret_h = close(entry+h)/open(entry)−1`，h ∈ {1,3,5,10,20}；报告必须注明"未含费用"（或引用 costs.py 假设）。
- **Tier2 IC/分层**（`myquant ic`）：RankIC 序列、ICIR、IC 衰减、5 分位单调性、日横截面样本数分布。
- **指标度量**：胜率、均值/中位数、盈亏比（profit_factor）、RankIC/ICIR、分层单调性、**信号密度**（signals/年/千股）与**换手代理**（持仓重叠度）。
- **市况分层**：所有结果按 `amv_regime`（0/1）分组报告稳健性。
- **宇宙**：修正后股票宇宙（`list_symbols`，剔 star/b/债券/基金/指数），含退市股。

## 2. 防过拟合协议（硬性）

| 数据段 | 用途 | 规则 |
|---|---|---|
| **IS 2015-01-01 ~ 2021-12-31** | 参数搜索/开发调试 | 网格扫描只准在此段跑 |
| **OOS 2022-01-01 ~ 2024-12-31** | 样本外验收 | **只允许审查者跑**，每指标限：最终候选参数 ≤2 组 + z哥原版基线 1 组，各一次；开发期任何人不得查看 OOS 结果 |
| **封存 2025-01-01 ~ 数据末** | 终检（上线前） | 研究阶段完全不许触碰 |

- **基线强制**：每份 OOS 报告必须并排给出 z哥原版参数结果；优化版 OOS 赢不了基线 → **如实报告"不采纳"**，这是合法结论不是失败。
- **邻域稳定性**（IS 内检验）：最优参数点的全部 ±1 步邻居必须满足——核心指标（h5 均值 & 盈亏比）≥ 最优点的 70%，且邻域中位数仍优于基线；不满足视为悬崖点，弃用。
- **多重比较意识**：每卡网格 ≤ ~200 组合；报告 IS top-5 而非单点，候选从 top-5 中按稳定性选。
- **信号密度下限**：年均信号 < 30 的参数组不进候选（统计不可靠）。
