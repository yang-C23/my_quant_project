# ADR-0006：可信长期数据与现金流研究

日期：2026-10-20。状态：用户批准实施。

用户批准的重启总计划取代此前将Qlib视为唯一研究存档、按模型身份固定职责、
按全市场统一末日追加数据的决定。历史ADR、任务卡和报告保留为证据。

决定：原始证据和版本化Parquet为底座，DuckDB查询，Qlib可重建；
数据修改先构建新快照，验收后原子切换；公式、单位、许可与发布时间单独验收；
收益使用真实现金流账本，股票旧费用模型不直接套用于ETF。
所有agent共用AGENTS、ONBOARDING及任务看板。

代价：保留快照与原始版本占用更多磁盘；全量逐证券比对比简单追加更慢；
免费来源缺少许可或历史发布时间证据时不能宣称正式研究已完成。
收益：可以解释和重放结果，失败可定位、可回滚，数据问题不会自动变成交易建议。
