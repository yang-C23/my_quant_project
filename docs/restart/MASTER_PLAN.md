# 量化项目重启总计划：可信数据、宽基与红利低波长期投资、可复现研究及自动提醒

本计划完整合并《量化项目重启：可信数据、宽基长期投资与可复现研究》和《宽基与红利低波长期投资平台重构计划（更新版）》。重复内容合并表述，全部研究范围、审计发现、数据要求、策略实验、执行约束、验收标准及交付内容均保留；不同策略版本分别评测。

## 一、项目目标、研究范围与当前基线

### 1. 项目目标

重新接手并恢复现有量化项目，审查全部代码、数据、历史研究结果及相关文档，建设能够长期维护的平台，支持：

- 持续采集、审查、清洗、复权和保存可信数据。
- 按固定代码、配置及数据快照复现研究。
- 比较宽基与红利低波的长期投资方法。
- 解释买入、停止定投、加仓和减仓的原因。
- 由不同 agent 使用同一套文档接手、实施、审查和交接。
- 每日监测，生成月度定投和事件驱动的投资提醒。

**实施原则：先修复工程与数据，验收数据后开展新研究；收益与风险通过实验计算，不预设策略有效。**

个股数据用于指数核查、基本面验证和必要的因子重建，本轮投资研究集中于指数与ETF。

### 2. 投资设定

- 同时评估境内ETF/QDII和海外ETF，两类投资渠道分别处理。
- 免费数据优先；付费数据列出覆盖、许可、费用和替代方案，不自动购买。
- 使用“已有本金＋每月新增资金”的投入方式。
- 本金默认分12期投入，允许极端行情触发额外投入。
- 同时比较纯择时与保留长期底仓。
- 兼顾长期复利和回撤，将约30%以内的历史样本外最大回撤作为研究目标，不作为未来保证。
- 每日监控、按月定投、事件触发加仓建议；交易由用户执行。

### 2. 数据档案、授权与准入

每个来源建立档案，记录：

- 发布者、获取地址、访问方式及故障替代方案。
- 覆盖范围、字段定义、单位及计算口径。
- 更新频率、延迟、历史修订方式及访问限制。
- 费用、免费额度、个人使用、长期留存及再分发许可。
- 来源质量检查、交叉核验结果和已知缺口。

**公开可访问、免费使用、开源采集代码、允许长期保存和允许再分发分别核查。**

缺少明确长期留存依据的数据，不作为唯一历史底座。付费来源先明确能够补齐什么缺口及其使用条件，不因付费就默认数据正确。

每份数据至少记录交易日期、首次可用时间、获取时间、修订版本和校验结果。只有通过覆盖、复权、时间戳及交叉核验的数据才能进入正式研究；无法证明历史可获得性的估值单独进入探索报告。

### 3. 雪球市场温度审查

对[雪球基金估值中心](https://danjuanfunds.com/djmodule/value-center)核对：

- 估值定义、统计窗口和成分处理。
- 亏损企业及负盈利处理。
- 百分位算法、历史修订和信息可得时间。
- 与官方数据、自算结果之间的差异。

只有能够解释公式和历史口径的部分才进入正式研究。无法解释的差异明确列出，不直接将网页展示值当成标准答案。

### 4. 三层存储结构

| 层次 | 保存内容 | 格式与要求 |
|---|---|---|
| 原始层 | 原始文件或响应字节、来源、获取时间、校验和、解析器版本 | 在许可范围内保留原始格式；修订追加保存，不覆盖旧版本 |
| 标准层 | 清洗后的行情、公司行动、证券信息、估值、成分及其他标准数据 | 带明确Arrow schema的Parquet＋ZSTD，按数据集、市场和年份分区 |
| 研究层 | 复权序列、因子、市场温度、信号、现金账本和回测结果 | 版本化保存，能够从标准层重建 |

元数据、数据契约和快照清单采用UTF-8 JSON。加入schema版本、迁移规则、校验和、备份及恢复演练，避免依赖单一软件专用二进制格式。

### 5. 统一字段类型

- 证券代码使用字符串，保留前导零和市场标识。
- 交易日使用日期类型。
- 发布时间、首次可用时间和获取时间使用UTC时间戳。
- 成交量使用整数，并明确股、份、手或合约等单位。
- 价格、收益及指标使用float64。
- 现金账本使用Decimal。
- 币种、交易所、价格精度和数据口径显式记录。
- 缺失值保留缺失语义，不转换为零。

### 6. 清洗与异常处理

检查唯一键、重复记录、日期覆盖、交易日历、异常价格、成交量单位、停牌和跨来源差异。

异常数据进入隔离区，保存原值、异常原因和处理依据。证券类别、特殊统计代码及公司行动造成的变化分别识别，不进行无法解释的统一修正。

### 7. 复权、分红与收益核算

- 原始不复权行情、分红拆分事件和复权因子分别保存。
- 前复权、后复权和含分红总回报明确区分，并绑定数据快照。
- 公告日、除息日、登记日及支付日分别记录。
- 除息后的应收分红计入账户权益，到账后才成为可用现金。
- 持有基准在分红到账后的下一可交易时点再投资。
- 择时策略将分红纳入现金池，按策略规则使用。
- 使用复权收益时不重复追加现金分红。
- 使用真实现金账本时，以原始交易价格处理成交和公司行动。
- 指数价格收益、指数全收益、ETF净值和ETF市场价格分别保存和报告。
- 已反映在基金净值中的费用不重复扣除。

基金规模变化不直接标为资金流入；根据份额变化估算的资金流必须记录计算公式、拆分调整及误差。

## 四、固定研究协议、策略实验与执行规则

### 1. 账户、资金与成交

默认示例账户为每个市场本币本金100,000、每月新增1,000，参数可替换；另做本金规模和月供比例敏感性分析。

所有策略使用相同日期、相同金额的外部现金流。等待投入的现金始终计入账户，现金收益以零为基准，另列可实际获得的现金管理情景。

仅使用决策时已经公开的信息，最早在下一可交易时点成交。分别处理：

- 境内外交易日历和交易时间差。
- ETF交易单位、佣金及滑点。
- 分红税情景和汇率。
- 境内QDII的实际成交价格及折溢价。
- 已计入净值的基金费用，避免重复扣除。

指数全收益研究和真实ETF投资分别报告。

### 2. ETF历史选择规则

在各回测起点筛选：

- 当时已经上市至少60个交易日。
- 跟踪同一目标指数。
- 非杠杆产品。

在符合条件的产品中，选择此前60日成交额最高者。不得使用今天的规模排名、当前存续产品或事后表现回选历史赢家。

### 3. 基准与策略实验矩阵

| 实验组 | 比较内容 |
|---|---|
| 无条件投入 | 本金分期投入并持续定投；本金立即投入后持续定投 |
| 估值择时 | PE分位策略；PB、股息率、盈利收益率与国债收益率差作为独立替代实验 |
| 恐慌立即入场 | 低估期间发生恐慌后，在下一可交易时点加仓 |
| 恐慌后企稳入场 | 对同类恐慌事件等待企稳确认后加仓 |
| KDJ | `J<0`单独使用，以及与低估条件组合 |
| 底仓配置 | 上述策略用于全部资金，与“50%长期持有＋50%择时”比较 |
| 红利低波 | 将同一套持有、定投、估值及恐慌规则用于红利低波研究组 |
| 风格组合 | 同市场“宽基50%＋红利低波50%、每年再平衡”与单独持有比较 |

“底仓／择时”和“宽基／红利低波”是两个独立实验维度，分别配置、报告。

### 4. PE历史分位策略

使用指数自身的历史PE分位：

- 主版本为过去10年窗口。
- 5年窗口及扩展历史窗口作为独立实验。
- 仅使用当时已知的历史观测，并要求相应预热长度。
- 窗口不足时不生成对应信号。
- 不同指数的估值计算口径分别审查。
- 负盈利、缺失值、口径变更及未经验证的历史重述，不解释为极低估。

边界统一为：

| PE历史分位 | 行为 |
|---|---|
| 低于40% | 允许按预算买入 |
| 达到40%、低于80% | 暂停新增投入 |
| 达到80% | 按选定退出实验启动分批减仓 |

首次低估买入时，将可投入的存量本金现金分为12份。合格月份投入一份及当月已到账定投额度。

暂停期间现金累积；恢复买入时不默认一次投入全部结余。发生减仓后再次进入低估区，按新一轮可用现金重新划分预算。

### 5. 两种退出方式分别回测

**时间分批退出：**

达到80%后，锁定本轮待退出份额，在三个符合高估条件的月度执行日分别卖出三分之一。

**分位分层退出：**

| 分位阈值 | 累计退出目标 |
|---|---|
| 80% | 本轮锁定份额的三分之一 |
| 90% | 本轮锁定份额的三分之二 |
| 95% | 本轮锁定份额的全部 |

两种规则独立评测。保留底仓的实验只对择时部分执行退出。

### 6. 替代市场温度

分别评测：

- PB历史分位。
- 股息率历史分位。
- 盈利收益率。
- 盈利收益率与国债收益率之差。
- 红利低波组的股息率及其相对国债收益率的吸引力。

每个指标记录公式、历史窗口、信息可得时间、缺失处理及适用范围，与PE策略使用相同资金账本比较。

### 7. 恐慌、企稳与动态加仓

首组可跨市场复算的恐慌条件固定为同时满足：

- 距过去252个交易日高点回撤至少20%。
- 五日收益达到此前60日波动率折算至五日尺度后的负两倍标准差阈值。

比较两种入场：

- **立即入场：** 触发后在下一可交易时点执行。
- **企稳入场：** 事件后20个交易日内，出现连续五日不创新低，且收盘站上十日均线，再于下一可交易时点执行。

事件加仓：

- 默认增加两个本金分批额度。
- 受实际可用现金限制。
- 消耗剩余投入预算。
- 不借用未来月供，不使用杠杆。
- 20个交易日内最多触发一次。

另测恐慌阈值、确认长度和加仓额度的邻域稳定性，检查结果是否依赖精确参数。

### 8. 杠杆、期货和期权信号扩展

逐项加入并评估样本外增量价值：

- VIX。
- 融资收缩。
- 股指期货贴水及基差。
- 期权偏斜。
- 深度虚值期权活动。
- 0DTE活动。
- 明确持仓方向假设的Gamma指标。

期货基差校正期限、利率、分红和换月影响。期权成交量及未平仓量本身不能证明真实爆仓，也不能确定做市商净Gamma；相关假设必须公开记录。[Cboe研究](https://cdn.cboe.com/resources/education/research_publications/gammasqueezes.pdf)

可靠历史数据不足的指标标记为尚不可验证。只有在验证阶段显示增益、并经最终样本外检验支持的指标才纳入候选操作规则。

### 9. 红利低波专项研究

除共同策略外，增加：

- 分红再投资总回报与现金分红两种展示。
- 将收益拆分为价格变化和分红贡献。
- 股息率及股息率相对国债收益率的吸引力，与PE温度比较。
- 行业集中、分红削减和利率变化的阶段分析。
- 指数选样、成分权重、调样规则及其历史变化审查。
- 基金跟踪误差、交易费用和运作费用影响。
- 长期落后成长风格区间及其持续时间。
- “宽基50%＋红利低波50%、每年再平衡”对回撤和恢复时间的改善程度。

使用当时的成分、权重和编制规则，不能用当前成分倒推历史。

### 10. 历史长度与证据分层

严格分开：

1. 指数发布前的回溯数据。
2. 指数发布后的历史记录。
3. ETF上市后的可投资历史。

科创等短历史标的仅报告实际支持的窗口，不补造10年或15年业绩。

512890于2019年上市，515100于2020年成立，其ETF真实投资记录不能延伸为15年；指数历史和基金历史必须分别标注。[512890披露](https://www.sse.com.cn/disclosure/fund/announcement/c/new/2026-03-18/512890_20260318_FNWM.pdf)、[515100资料](https://www.igwfmc.com/main/jjcp/product/515100/detail.html)

缺乏完整估值历史或信息发布时间证据时，明确指出哪些实验无法严格完成，探索结果不混入正式可投资结论。

## 五、验证、交付、自动化与阶段验收

### 1. 数据与工程验收

必须完成：

- 全量唯一键、覆盖范围及量纲检查。
- ETF价格和成交量单位验证。
- 分红、拆股、除息和到账的独立手算样例。
- 前后复权、总回报和现金账本核对。
- 更新幂等、逐证券补漏和历史修订测试。
- 断点恢复、失败恢复、原子发布和快照回滚测试。
- 快照回放及备份恢复演练。
- 同一代码、配置和快照下的结果复现。
- “追加未来数据不改变过去已产生信号”的检查。
- 存取款不被计为投资收益的账本测试。

来源中断、字段变化、数据过期或关键估值缺失时，暂停生成依赖该数据的买卖建议，并记录具体原因。

### 2. 研究验证

- 先冻结实验清单、策略规则和参数，再运行正式比较。
- 按时间顺序进行训练、验证和滚动样本外评估。
- 保存全部试验，不只保存表现最好的结果。
- 报告完整历史及数据支持的10年、15年和滚动窗口结果。
- 展示最差窗口、不同市场阶段和参数邻域表现。
- 重叠窗口不当作独立样本。
- 恐慌事件按事件簇统计，避免把同一次下跌中的连续信号当成多次独立成功。
- 最终样本外用于评价，不据此反复调参。

### 3. 统一绩效报告

每个策略、指数、ETF和组合统一报告：

| 维度 | 指标 |
|---|---|
| 收益 | 复利年化、剔除外部现金流的时间加权收益、XIRR |
| 资金结果 | 累计投入、期末财富、现金余额与现金占比 |
| 风险 | 最大回撤、恢复时间、最差窗口表现 |
| 执行 | 换手、佣金、滑点、其他成本 |
| 策略代价 | 踏空损失、长期等待现金的影响 |
| 证据 | 数据覆盖、历史类型、样本外结果及参数稳定性 |

账户收益计算不能将持续入金误认为盈利。约30%的回撤仅作为历史研究筛选目标。

### 4. 策略选择原则

在验证阶段比较收益与回撤，优先考虑：

- 规则简单、容易解释。
- 换手低，交易成本可控。
- 跨窗口、跨阶段表现一致。
- 对阈值和数据口径的小变化不敏感。
- 能够使用已验收、可持续获取的数据执行。

复杂择时没有可靠优势、证据不足、普通定投更优或保留底仓更合适，均可作为正式结论。按每个指数及风格分别给出操作规则和证据等级。

### 5. 最终交付

交付内容完整包括：

1. 全项目审计报告、问题清单、修复记录和旧结果分类。
2. 环境、依赖与运行入口说明。
3. 数据来源、授权、费用、覆盖与缺口矩阵。
4. 标准数据契约、清洗规则、复权及现金账本说明。
5. 可回放的数据快照和可复现研究配置。
6. 九个宽基指数的策略比较报告。
7. A股与美股红利低波专项报告。
8. 宽基与红利低波组合研究报告。
9. 各指数及风格的买入、停投、加仓、退出规则与适用边界。
10. 多agent共同工作文档、接手入口、任务状态和交接规范。
11. 每日信号记录、异常记录及自动化运行说明。

### 6. 每日监测与提醒

提供每日监测、月度定投和事件加仓的统一入口。

每条提醒包含：

- 标的和策略版本。
- 数据日期及使用的数据快照。
- 触发条件和具体原因。
- 当前预算及建议使用额度。
- 下一可交易时点。
- 信号失效条件。
- 数据异常或证据不足的说明。

过期或异常数据输出“暂停评估”，不继续生成依赖该数据的交易建议。

先进行20个交易日影子运行，检查更新、计算、异常处理和提醒可靠性；影子运行用于验证系统运行，不替代长期策略验证。交易由用户执行，不自动下单。

### 7. 实施顺序与阶段门槛

| 阶段 | 主要工作 | 进入下一阶段的条件 |
|---|---|---|
| 1. 基线与审计 | 环境、代码、工作树、关联工具、数据及旧成果盘点 | 可恢复基线、问题清单和运行入口明确 |
| 2. 工程与通达信修复 | 环境隔离、单位、公司行动、增量更新和现金账本修复 | 关键金融语义与工程测试通过 |
| 3. 通达信更新 | 逐证券补漏、历史修订、派生重算和快照发布 | 更新验收通过，可重复执行及回滚 |
| 4. 替代数据验收 | 数据源、许可、覆盖、清洗、复权及时间戳验证 | 正式研究所需数据通过准入，缺口明确 |
| 5. 基准研究 | 持有、定投、PE策略及替代温度 | 资金、成交和绩效口径统一，结果可复现 |
| 6. 扩展研究 | 恐慌与企稳、KDJ、底仓、红利低波和风格组合 | 完成样本外、窗口及参数稳定性比较 |
| 7. 操作规则与自动化 | 各标的规则、每日信号及提醒 | 规则可解释，异常处理有效，完成影子运行 |
| 8. 长期维护 | 数据更新、来源变化监控、版本迁移、备份恢复和agent交接 | 持续保留可追溯、可复现和可恢复能力 |

总体顺序固定为：**环境与旧成果审计 → 修复并更新通达信 → 替代数据验收 → 基准回测 → 红利低波与动态策略比较 → 操作规则 → 日常监测与提醒 → 长期维护。**
