# 现金池择时、恐慌后入场与长期复利：下一阶段执行协议

本文件是[总计划](MASTER_PLAN.md)的实施细化，不删除其九个宽基、红利低波、
PE/PB/股息率、两种退出、渠道、数据准入和长期维护要求。
任务状态只在[任务看板](../tasks/STATUS.md)更新。
截至2026-10-20，用户已授权执行；现金池与阶段状态机已实现并通过首轮金融测试，
本文件中的新策略和衍生品条件尚未完成真实历史收益验证；
现有结果解释及本轮核对见[策略复核](STRATEGY_REVIEW.md)。

## 1. 用户已明确的约束

- 先做透免费和已有数据；不购买数据。
- 投资周期以5—10年计，初期1—2年浮亏可以接受；同时关心回撤、回本时间和年化。
  这不是承诺2年必回本，也没有提供可据此固定的最大浮亏上限。
- 渠道大概率是境内ETF/QDII，海外或双渠道仍保留。标的美元收益不能直接冒充QDII人民币收益。
- 本金/月供暂用本币100,000/1,000，另测月供为本金0.5%、1%、2%。
- 每月入金不等于每月买入：先积累现金，符合估值/压力/企稳条件才分批投入，达到退出条件分批卖出。
- 比较等待6、12、24个月的资金利用和机会成本，不把这些时间自动变成强制买入期限。
- 寻找参数附近也有效的区间和可解释的动态规则，不追逐历史收益最高的单一参数。

无须用户再提供行情文件才能推进。已有合法授权的历史估值、ETF分红支付日或期权导出可补缺，
但不是本轮免费研究的前提；不要求在聊天中提供账户密码或API密钥。

## 2. 研究问题与证据等级

待验证问题是：相同入金下，等压力出现并减弱后分批投入，能否改善5/10年投资结果，
并减少入场后继续下跌的损失；改善是否足以补偿长期持币与反弹踏空？

“低估”“价格跌得深”“融资收缩”“流动性紧张”“做市商净Gamma”是不同概念。
不把它们合并命名为已证实的爆仓，不设想能观测“所有杠杆已清零”。

三条研究路径分别出结果：

1. 已有价格与免费压力代理：可以开展**探索性事件研究**，明确不含完整股息或真实ETF执行。
2. 历史估值及发布时间通过准入：才能开展对应PE/PB条件的正式比较。
3. ETF公司行动、支付日、历史名录、渠道和许可通过：才能形成真实账户的可投资结论。

估值缺失不会被当作低估；也不以价格跌幅偷偷替代PE后仍沿用“估值策略”名称。
所有结果保留正面、负面及暂停项。正式提醒门槛维持，影子运行另按真实交易日累计。

## 3. 现金池与执行规则：先登记，再计算

旧 `dca`、`kdj`、`kdj_core50` 保留为冻结对照。新增规则使用独立版本，
不回写旧实验，也不直接把现有 `kdj` 重命名为完整现金池策略。

主实验采用“现金池／剩余批次数”：

1. 等待期全部新增资金记入现金池；收益基准为0，另列有实际依据的现金管理情景。
2. 首次合格入场时开启一轮，剩余批次数 `r=N`，主版本 `N=12`；3、6批为预登记对照。
   首批在信号之后下一可交易时点执行，后续采用月度批次；所有信号依真实可得时间计算。
3. 合格月度执行日按**当时可用现金 `C/r`**买入一批。C包括已到账本金、月供、
   历史卖出净额和可使用的已到账分红；不包括未来月供或应收股息。
4. 等待期间新月供继续进入C；恢复投入时重新按C/r计算，不遗漏积累的钱。
   除非r恰好为1，不因恢复信号就默认全仓。
5. 恐慌立即入场或企稳版本可额外使用2批，消耗r，月度与事件同日先合并预算，
   不重复支出；总额不超过现金，20个交易日内最多一次事件加仓。
6. 成功成交才消耗对应批数；交易单位、费用造成的尾差保留现金。
   因停牌/缺价等未成交不得算成已投入。具体部分成交记账通过手算测试后冻结。
7. 一轮批次耗尽后，后来到账资金进入下一轮等待池；下一个合格执行日才启动新一轮。
8. 达到高估阈值按原计划的“3次高估月份分批”或“80/90/95分位累计分层”分别退出，
   锁定本轮待退出份额。只退出择时部分；不在同一执行日又买又卖。
9. 退出后重返低估，依总计划终止旧退出安排，以实际现金开启新投入轮次。
   不能因为每个低估日到来都重置批数。

PE与PB先各自比较，主低估线40%、主退出线80%，不先混成一个无法解释的温度。
估值与压力联用时，要求压力事件当天已低估、确认入场时仍低估；
不会用确认日才出现的低估倒填到过去的压力事件。
为隔离信号本身，第一组阶段比较统一额外批次数为0；
原定额外2批及1/3批邻域作为独立执行实验保留。
入口分位20/30/40/50%、退出75/80/85%仅做少量预登记的一次一项邻域试验；
5年、10年、扩展窗口沿用总计划并严格预热。负盈利、口径变更及缺少可得时间记录的资料暂停。

动态投入另立版本：普通低估一批、深度低估两批，或者仅由已知波动控制单批风险；
与固定批次逐项比较，不同时开放多套自由参数。以上是待检验假设，尚不是最优操作规则。
价格恐慌研究若没有合格估值，可以研究入场事件；不会为它编造“高估退出”。

底仓0%、25%、50%作为独立配置维度；与相同底仓、相同资金计划的无择时对照比较。
宽基/红利低波50:50年度再平衡仍为另一维度，不能与“底仓50%”混为一谈。

2026-10-20执行登记：`configs/cash_pool.yaml`共197项假设，额外包括0/25/50/75%的
固定入金股票比例＋余款现金对照（持有后允许权重漂移，并非每日恒定仓位）。
全组账户在252条价格预热数据之后开始；ETF另需60条上市交易记录。
起点相同的对照从同一天入金。只有约10年原始价格的标普500因此不能声称有10年完整阶段策略证据。
5/10/15年滚动窗口分开统计，不混合年限。FINRA月度发布滞后1/2月、CFTC观察日滞后10/17日
是显式敏感性假设，不是已经验证的真实发布日期。分红再投资与保留现金分红独立登记。

## 4. 因子、第一方来源及可证明的边界

| 研究对象 | 首选证据与来源 | 处理要求 |
|---|---|---|
| 下跌加速、异常波动 | 交易所指数/ETF行情；发行人NAV、份额及分红 | 252日回撤、5日跌幅相对预先波动率、成交额异常分别计算；NAV折溢价必须对齐同一信息时点，不能拿隔夜美国NAV机械比较当日QDII |
| 恐慌及恐慌消退 | [Cboe VIX历史](https://www.cboe.com/tradable-products/vix/vix-historical-data) | 已有长历史；研究高分位后回落的增量，核查时间和许可；其他期限/偏斜指数逐个验收，不假定都免费完整 |
| A股融资收缩 | [上交所](https://www.sse.com.cn/market/othersdata/margin/detail/index.shtml)、[深交所](https://www.szse.cn/marketServices/deal/finance/) | 余额、买入及偿还分别建表；偿还包含自愿偿还和强平等，不能单独识别爆仓；汇总与明细范围不同，不能只用当前标的反推历史 |
| 美股融资规模 | [FINRA](https://www.finra.org/rules-guidance/key-topics/margin-accounts/margin-statistics) | 历史从1997年起，月度数据通常次月第三周发布；仅作慢速环境变量。记录2010统计范围及2021报告方法变化；未知真实发布时间不得伪装成严格PIT |
| 期货仓位拥挤 | [CFTC历史档案](https://www.cftc.gov/MarketReports/CommitmentsofTraders/HistoricalCompressed/index.htm)及[公布日程](https://www.cftc.gov/MarketReports/CommitmentsofTraders/ReleaseSchedule/index.htm) | TFF杠杆基金净/总头寸、OI占比为代理；通常周五15:30纽约时间公布此前周二数据，逐周处理节假日或异常延迟，不能回填到周二交易 |
| 期货异常贴水 | [中金所历史](https://www.cffex.com.cn/lsjysj/)、[CME定价说明](https://www.cmegroup.com/trading/equity-index/fairvalue.html) | 同时点现货/期货、剩余期限、利率、当时预期分红、换月分别处理；不用后来实际分红回写当时理论基差，不能把全部贴水都视为恐慌 |
| 深虚值期权、0DTE与偏斜 | 交易所公开统计；完整链候选为[Cboe EOD](https://datashop.cboe.com/option-eod-summary)或[区间报价](https://datashop.cboe.com/option-quote-intervals) | 本轮没有验收可免费长期保存的完整历史链。付费产品只登记缺口，不购买。免费汇总不能冒充完整链，EOD不能代替日内0DTE压力 |
| Gamma | 交易所可辨方向的持仓资料，或显式情景计算 | OI和成交量无法确定做市商净方向；只有假设时标记“Gamma情景”，不能称净Gamma观测 |
| PE/PB/股息率及红利低波 | 中证、国证、S&P、Nasdaq及基金发行人 | 查方法、成分及发布时间；近期横截面不能支撑历史分位。红利低波公司行动/支付日补齐前，不引用原价拆分亏损 |

每个来源保存地址、发布时间依据、取得日期、原始哈希、解析器、字段单位、覆盖、
修订方式及长期留存/使用条件；公开可访问不等于开放许可。缺许可依据时不能作为唯一永久底座。
对于缺确切发布记录的月度资料，保守滞后假设只能进入敏感性探索，不能因此宣布已通过PIT验收。

Gamma机制要分方向：在其他条件相同时，做市商负Gamma对冲可能放大波动，
正Gamma对冲可能缓和波动；总量暴增不等于净风险暴增。
依据[Cboe对SPX 0DTE的解释](https://www.cboe.com/insights/posts/volatility-insights-evaluating-the-market-impact-of-spx-0-dte-options/)，
核对买卖、开平、参与者类型及覆盖交易所；不把其特定历史样本结论外推成所有时段无影响。

深虚值期权分别研究Put/Call、固定Delta或价外程度、固定到期天数、有效买卖报价中间值、
价差与成交名义金额；不能把一分钱涨到两分钱的过期成交当可靠“暴涨”。
0DTE在2022年SPX增加周二/周四到期后覆盖发生变化
（[Cboe公告](https://ir.cboe.com/news/news-details/2022/Cboe-to-Add-Tuesday-and-Thursday-Expirations-for-SPX-Weeklys-Options-04-13-2022/default.aspx)），
需要分制度阶段，不能将今天的每日到期结构倒推15年。没有这些数据，保留“不知道”的结论。

## 5. 6—10小时首轮工作包

这是下一轮连续研究的预计工作量，数据站点失败时执行独立分支并记录缺口。
不承诺几小时补齐所有历史许可、长期估值和完整期权链，也不以耗时替代验收。

| 预计累计时间 | 具体工作 | 必须留下的产物/门槛 |
|---|---|---|
| 0—1小时 | 冻结本轮复核基线；完善现金池状态机与手算；拆开初始本金、月供、股息、卖出收入和批次预算；统一仓位对照 | 新版本规则JSON、资金守恒/重复入金/暂停恢复/分批退出/未来数据不改变旧信号的测试；金融测试失败先修复 |
| 1—3小时 | 扩展免费CFTC、FINRA、Cboe和沪深融资数据；中金所逐月补齐；补估值、基金分红、份额及支付日证据；不让单站点反复重试拖住其他任务 | 原始与标准层快照、覆盖和授权矩阵、逐项准入/探索/暂停裁定；历史日期与实际发布时间分离 |
| 3—4.5小时 | 做压力事件研究：恐慌即入、五日不创新低且站上十日均线后入、压力消退后入分别比较；再单独加入VIX、融资和基差 | 全事件表，含未企稳、信号过期和未入场案例；入场后20/60/252日继续下跌、1/3/6/12月表现、反弹踏空 |
| 4.5—6.5小时 | 跑现金池＋分批投入/退出；无条件DCA/一次投入作基准；估值、价格压力、企稳、KDJ逐项消融；0/25/50%底仓、等待6/12/24月诊断 | 同起止日、资金、执行、可得数据的完整结果，及相同投入比例对照；新策略只在合格输入上执行 |
| 6.5—8小时 | 5/10年和可支持的15年窗口；按时间滚动检验；留一轮危机核对、参数邻域、成本/汇率/QDII溢价情景；红利低波分开 | 全部试验登记、最差窗口、恢复期、回本概率、事件簇置信区间及不确定性，不只留赢家 |
| 8—10小时（视数据条件） | 复放、针对性代码审查和异常演练；整理各市场候选规则、否定结论和下一数据缺口；仅将通过门槛的规则加入影子观察 | 可复现报告、代码/配置/快照指纹、任务交接；没有证据优于简单规则时明确报告 |

每30—60分钟保存一个阶段检查点：已完成、失败及原因、下一命令、输出路径和哈希。
网络来源多次失败时保留日志并继续已有数据的独立研究，不制造替代值。
反复验证针对新改动、失败、数据差异和金融假设；不无目的重复绿灯测试。
GPU不是日线账本研究的必要条件；先保证数据与时间语义。

## 6. 公平比较与防止找到虚假的“甜点”

- 保留所有原规则，新的现金池规则独立编号；原报告已看过的区间不再称为“未见最终样本外”。
  历史按时间切分仍可做回溯检验，但标明已经研究过；新增规则冻结后的未来影子数据才是前瞻证据。
- 共同窗口只纳入当时已发布且有覆盖的指数；科创短历史单独比较，不造10年收益。
  数据长度不同的因子采用相同交集样本的增量比较，同时报告样本损失。
- 先验证现金池规则，再在其上一次加入一个信息维度；不穷举所有阈值的笛卡尔积。
  阈值附近表现平台优先于一个特别尖锐的最佳点。
- 因子使用当时可得历史分位实现自适应；预测参数只允许在过去训练段更新，
  预定更新频率并冻结验证段。不会看完整个熊市后重新定义“恐慌已经过去”。
- 现有5日跌幅门槛使用截至前一日的60日波动，其中与跌幅窗口有重叠；这是因果的，
  但可能削弱冲击信号。另登记“冲击开始前固定波动”版本，不能悄悄替换后选好结果。
- 美股当前只有close，而A股有low。首轮共同价格压力/企稳比较统一收盘口径；
  有真实OHLC后的日内低点确认另立版本。
- 等待企稳必须把未出现确认、等到反弹后买入、最终没交易的事件也计入；
  共同财富比较从同一个事件识别日开始，不能为企稳策略删除等待成本。
- 恐慌按事件簇统计，不把同一轮熊市的每个信号视作独立样本；跨市场同期危机也相关。
  置信区间使用事件/时间块，少数危机不能支撑很精确的胜率。
- 用相同长期底仓和相近市场投入比例的简单对照隔离选时作用；
  低回撤若主要来自长期闲置现金，应如实报告。
- 20个交易日影子运行只验证操作可靠性，不能证明5—10年复利优势。

## 7. 最终要回答用户的问题

每个宽基、红利低波和组合分别展示：

1. 同一资金路径的年化TWR、XIRR、期末财富、累计入金及现金；明确价格代理还是含分红真实账户。
2. 账户历史高点回撤、最长未恢复期、每笔入场后的最大不利变动，以及相对实际累计投入的浮亏。
3. 持有5/10年后亏损的窗口比例、最差起点、1/2年回本情况和长期未回本案例；
   主账户窗口从首次入金开始，包含等待现金期，另列每笔入场后的持有结果。
   重叠窗口比例不是独立概率估计。
4. 等待6/12/24个月的现金积累、错过上涨、买到更低价的收益和机会成本。
5. 哪个额外因子确有增量、在哪些阶段失效；数据不足和简单策略更好都允许成为结论。
6. 若有可信候选，给出触发、分批额度、退出、失效和暂停条件；尚未通过准入的规则不给实盘买卖提醒。

目前没有证据保证存在同时提高年化、减少回撤、缩短回本且经常触发的“甜点”。
本轮的任务就是检验这种机会是否存在、适用于哪些指数，以及代价是什么。
