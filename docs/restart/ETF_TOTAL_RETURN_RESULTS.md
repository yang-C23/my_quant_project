## 1. 已经能回答的问题

1. **长期持有仍应保留为核心比较基准，但“十年必回本”不成立。** SPY与QQQ含分红后，
   仍有完整十年账户低于累计投入本金。QQQ的最差本金亏损和恢复时间显著更大，不能只看收益中位数。
2. **恐慌后企稳能够改善部分危机起点，却没有普遍超过从一开始分批投入。**
   完整五年配对中，等待常损失财富；十年配对较有利，但实际独立入场事件只有3—4次，
   不能把多个原点等到同一次危机当作多次独立验证。
3. **机械退出有风险与收益的交换，不能推广成“应该统一止盈”或“永远不卖”。**
   SPY部分十年事件组退出获益，QQQ同类规则大多牺牲收益；同一标的五年和十年也不同。
4. **低估→压力→企稳的完整链条还没有足够历史证据。** 有历史版本的标普估值代理很稀疏，
   纳指自身长期PIT估值仍缺。严格联合规则及追加的同事件规则都没有满五年样本，不能报告为零收益，
   更不能宣布已经找到最优买点。
5. **真实等待利息不能消除等待成本。** BIL的历史分红、实际支付和费用已经计入；
   低利率年份短期净收益可为负，长期等待仍可能错过大段上涨。

这支持封存当前探索阶段供审阅，后续优先解决渠道、数据准入和风险预算；不再扩大同一历史的阈值搜索。

## 2. 资金、策略名称与统计口径

本金100,000、每月新增1,000，各市场使用本币。美股为美元，未换算人民币；本金与月供只是示例。
美股佣金3bp、滑点5bp、整股交易；主组现金分配税为0，10%扣减另作敏感性。
原始价格成交，除息形成应收，支付后才成为可用资金；已在基金价格中体现的管理费不重复扣。
等待现金主组收益为0，BIL单独比较。交易在信号后的下一交易日收盘，不用当日收盘信息成交于同日。

| 名称 | 本轮含义 |
|---|---|
| DCA | 定期投入固定金额，通常不等待估值或技术条件；它不是本轮全部策略的统称 |
| 无条件现金池 | 从原点开始，现金池按剩余份数C/R分批投入；新增月供进入池内，12份用完后按登记规则续轮 |
| 恐慌立即 | 距252日高点跌至少20%，且五日跌幅超过前置60日波动率的负两倍五日尺度阈值 |
| 恐慌后企稳 | 同类事件后20或60个交易日内，连续五日不创新低且站上10日均线，次日买入 |
| `entry_pool_hold` | 等到首次入场后，不再要求后续月供满足入场条件，按12份现金池持续买入且不退出 |
| `none_core0` | 不退出；但后续择时资金仍受入场资格约束，不能把它误称为无条件持续买入 |
| `core0.5` / 50%底仓 | 每次外部入金的一半用于长期部分，另一半择时；不是恒定50%现金，也不是每日再平衡至50%股票 |
| 回到前高退出 | 回到事件前高点后，在三个合格月度日分批退出锁定份额；不是固定盈利百分比止盈 |
| 估值退出 | PE历史分位80%后分三次，或80/90/95%分层；两种独立评测 |
| KDJ / KDJ_core50 | 旧登记的J<0信号及其50%入金底仓版本；不能与本轮估值/企稳混称，完整旧比较仍保留 |

每年设一个账户原点，保留252交易日预热；首次可用年份可能从年中开始。
五年/十年从**首次实际买入**起算到满周年后的首个可交易日。对比等待与不等待时，
使用同一个资金原点、同额同日入金、同一个终点。不能把等待两年再持有十年与只持有十年直接比较。

年化为剔除外部入金的时间加权收益TWR复利年化；XIRR另计真实资金时点。
回撤基于单位化净值；本金亏损是账户权益低于累计外部净投入的比例。两者不同。
“回本时间”在这里主要报告最长连续本金不足的日历天数，尚未回本者保留右删失标识；
它不是从市场峰值到新高的天数，也不代表未来最长等待时间。
各列最差值可以来自不同账户。重叠窗口数量不是独立样本量，不估计无依据的成功概率。

## 6. 低估→压力→企稳：阶段已量化，证据仍不足

取得131个Shiller历史存档文件，最终129个同时通过内容完整性与存档摘要检查。
使用捕获时间和交易所实际收盘时间，仅取已结束月份的正盈利、最长185天新鲜度，
计算与同版本过去十年月度PE的中间排名；这仍是**历史存档版本代理**，不是官方每日指数PIT PE。
2008年无新鲜有效观测，2024—2026年也没有新鲜盈利；纳指自身估值没有补齐。
76个“原点×规则”因起点没有有效估值排除，另存清单，不把等待数据出现当低估等待。
账户开始后的断档仍会暂停估值操作，所以估值组等待包含数据中断，不能全部解释成主动择时。

严格低估恐慌/企稳和追加“同一压力事件内后来变低估也可取得资格”都没有满五年或十年样本。
追加研究只改变事件资格，不改40%阈值、60日确认或资金规则，属于已见结果后的探索，非样本外。
两版本最终成交逐笔相同；每日记录只有触发标记不同，持仓、现金、收益和指标完全相同。

2020年逐日案例解释了原因：

| 日期 | 阶段 | 当日代理估值分位 | 结果 |
|---|---|---:|---|
| 03-12 | 压力事件开始 | 43.48% | 未低于40% |
| 03-16 | 继续满足压力，估值变低 | 27.12% | 追加规则从当天开始取得资格，不能回写过去 |
| 03-30 | 首次满足五日不创新低及10日均线 | 43.22% | 企稳日再次超出40%，不买入 |

低估、恐慌和企稳并不总在同一时刻成立。此后有低估日，但未同时产生符合规则的企稳脉冲。
最早实际入场集中于2022-06-27，距截止不足五年。
不能因看到43.22%便把阈值调到44%并宣称成功；此案例说明规则的取舍，不识别最优阈值。
图表与全部逐日条件见审计目录`diagnostics-v4/event_sequence_2020.png`及同目录CSV。

此前VIX、期限校正基差、CFTC、FINRA、深度虚值期权活动等研究仍见[CASH_POOL_RESULTS.md](CASH_POOL_RESULTS.md)。
本轮没有凭这些代理宣称识别真实强平、做市商净Gamma或0DTE拥挤度。完整历史方向、报价和发布时间不足的指标继续暂停，
不为了补齐叙事把成交量当成爆仓。KDJ<0也没有被晋级为正式规则。

## 9. 1975年是否太早

1975年以来的标普日线用于压力情景和机制检查；它不是SPY上市前可交易的ETF含分红记录。
实际ETF研究从其可用行情及预热以后开始。没有把早期价格历史接成基金净值。
不同交易机制、费率、行业结构和利率环境，应分年代报告，而不是直接删除不利年代。

仅看2010年以后的无条件现金池，满十年SPY、QQQ各只有7个重叠队列：
年化中位数13.04%与17.43%，最差回撤约−33.10%与−34.86%，均无满期本金亏损。
这些比包含2000/2008危机的样本好得多，说明年代影响大；不能据近期表现保证未来只会经历约30%回撤。
旧价格指数分年代全表另存`price_only_era_diagnostic.csv`，与含分红ETF表分开。
ETF与价格指数收益差还包含起点/队列差异，不能全部归因于分红。

主研究3,697去重账户、886个规则/原点/期限队列、6,576条比较记录；其中358满期、334未满期、194未入场。
缺估值的76个原点/规则（对应152个期限请求）另列，未混进主动等待。
主组、来源敏感性、无月供、股息扣减、BIL及其来源敏感性、追加事件规则共9,835个账户，
均有独立账本核对；重算并比较59,717对产物，实际读取119,434个文件，零差异。
代码、规则和相同输入重放一致，不只比较年化接近。

美股股价跨源容差预先固定0.0001美元；超差另列。主组与来源敏感性的4,632行配对，
入场日、终点、状态未变；最大年化差0.02956个百分点，最大财富差5,168.64美元。
股息10%扣减只覆盖无条件基准，最大年化差0.26518个百分点，不能宣称所有策略已完成税后验证。
追加未来数据的特征/账户检查继续执行。摘要校验新增拒收一份早期存档后，
逐日重算8,488行标普估值：所有金融字段不变，因为该版本从未满足新鲜度；原冻结输入保留，勘误另存。

主组实测167.19秒完成3,697账户，约22.11账户/秒，12个账户worker、内部线程1。
峰值进程RSS合计约2.88GiB、USS约1.18GiB；采样CPU忙期约10.95核（p95），GPU利用率0%、基线显存87MiB。
这一工作负载采用CPU精确账本；不为提高GPU利用率搬迁串行现金逻辑。
此前同负载优化前后证据与GPU完整传输/同步基准见[性能报告](PERFORMANCE_AUDIT.md)，
不能把本轮3,697账户耗时与旧52账户直接计算加速比。

来源仍属探索准入，长期保存/再分发依据未全部明确；QQQ部分早期支付证据为发行人搜索呈现，
不是完整一手原始响应；估值稀疏且存在插值。样本均已见，不是新的最终样本外。
本轮没有完成全历史ETF名录选择、QDII税费/汇率/溢价、严格纳指PE/PB、完整Gamma/0DTE和未来20日验证。

## 11. 下一阶段的有限决策

| 决策 | 当前证据支持的处理 |
|---|---|
| 标普500长期持有 | 继续作为主要基准；以历史本金深亏和多年恢复约束投入风险，不能按十年保本安排刚性资金 |
| 纳斯达克100 | 保留成长风格研究；收益中位数高，但最差亏损明显更深，不以其替代全部风险预算 |

| 长期底仓 | 可减少踏空，需另检验固定风险配置；当前core50不是50%风险上限 |

| 实际投资渠道 | 用户选境内QDII/海外后，再计算可交易成本、税务、汇率、溢价与结算；现有美元结果不能直接照搬 |
