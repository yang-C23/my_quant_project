# 标普长历史、实际入场后5/10年与分批退出

研究日2026-10-21。用户要求继续研究，暂不收尾、不上传Git。
固定规则见[登记协议](ENTRY_HORIZONS_PROTOCOL.md)和`configs/entry_horizons_v2.json`。
本页以日历裁定后的v2为当前证据；v1、来源敏感性、失败探测与重放全部保留。
这仍是探索研究：美国使用不含分红的价格指数，修订盈利不是严格PIT估值，未生成交易建议。

**当前判断：标普的长历史不支持“回撤一直很小”。恐慌后企稳在部分买入后窗口改善表现，
但尚未证明等待它能普遍提高同一笔资金的最终财富；低估叠加企稳尤其依赖盈利口径与少数历史事件。
分批退出有明确的成功例和失败例，不能据此判定永不退出或机械止盈普遍更好。**

## 比较的投资行为

示例本金100,000、月供1,000；美国按美元、A股按人民币分别核算，不做跨币种财富排名。
入金在每月首个观测交易日到账，现金收益基准为零；本金及积累现金按12批规则投入。
现金池每次按“当前可用现金/剩余批数”分配，新增月供也参与分摊；并非每月1,000到账后立即全部买入。
一轮完成后，后续现金依对应规则开启下一轮。立即持有对照则将初始本金与后续月供直接投入。
佣金3bp、滑点5bp；指数份额是研究用可分割头寸，不冒充ETF成交。
A股ETF按100份交易单位，使用原价及已核查的除息/支付事件，应收分红到账后才可使用。

每个入场规则从实际首次买入观察完整5、10个日历年，周年后首个交易日结束。
同一队列内的退出与底仓策略共享此终点。跨规则的入场日不同，其终点也可能不同，
所以不能仅凭两组年化中位数的高低认定入场规则产生超额收益；必须同时看同起点、同终点的配对财富差。
每个队列保留四个对照：积累日起立即持有/无条件分批，以及入场日起立即持有/无条件分批。
入场日起对照将此前积累的现金合并投入，其XIRR计时从入场开始；与原账户比较期末财富时累计本金完全相同。

`none_core0`表示不卖出，但后续资金仍按原入场/低估规则使用；
`entry_pool_hold`表示找到该买点后12批投入，此后无条件继续投入并持有。
二者不是同一种“买入后长期持有”。`core0.5`表示每笔本金/月供的50%进入长期持有部分，
其余50%择时，**并非每天维持股票仓位50%**，也不是宽基/红利各50%的风格组合。
底仓在资金计划起日已经买入，其十年比较仍使用无底仓参考账户的首次择时成交日作为共同锚点；
不能将其称为“底仓自身首次成交后十年”。全计划收益与财富另列，包含底仓提前投资及择时等待。

下表“年化”均为剔除入金后的复利时间加权收益（TWR），不是把财富/累计投入直接年化。
“最差回撤”是账户TWR净值从高点回落；“本金亏损”是账户权益低于当时累计外部入金。
汇总使用全部满期队列；最差收益、最差回撤与最大本金亏损可能来自不同队列。
逐年起点与持有期高度重叠，不是独立样本，样本中位数不是未来收益预测。

## 完整持有期结果

v2包含12,479个去重后的真实账本、2,286个入场/期限队列、19,752行比较。
其中1,545个队列满期、465个已入场但未满期、276个尚未入场，后两类保留且不伪装成完整5/10年。
这是38组已登记入场特征的账户组合，不是12,479个独立投资假说。

### 分批退出与保留底仓

本表固定“企稳60”入场规则，后续择时资金仍服从相同的现金池规则，只改变退出或底仓。
恢复退出是价格回到本轮事件锚定高点后，在三个合格月度执行日退出三分之一。
这些账户与前表的`entry_pool_hold`有不同的后续资金规则，不能混为一项实验。

底仓减少等待造成的长期空仓，也会更充分承受下跌；没有将最大回撤自动限制在30%或50%。
恢复高点退出减少部分回撤，却容易卖掉后续长牛。两种结果都按完整历史保留。

**估值退出也有明确的正例，不能只展示不利结果：** 标普“低估+企稳60、盈利延迟12月”十年组，
不退出的年化中位数0.24%、最差回撤-53.47%、期末本金亏损12/34；

80/90/95%分层退出变为1.43%、-21.23%、0/34，财富差中位数+41,686.81美元。
但将盈利延迟改为6个月，同一入场组的时间退出把年化中位数从2.08%降至0.97%，
最差回撤从-53.31%降至-11.11%，财富差中位数-38,712.12美元。
这支持“退出有阶段性风险收益取舍”，不足以证明一个统一卖点。

### 看似甜点的参数为什么尚不能采用

将“低估+企稳60”的买入阈值由40%改为预登记的30%，延迟6月的十年结果看起来很好：
年化中位数10.57%、最差回撤-24.93%、期末本金亏损0/34。
但34个资金计划最终只有**两个不同买点**；满期队列等待中位数3,396天，最长9,423天（约25.8年），
把等待计入后，全计划年化中位数仅5.35%。它不是34次独立的“抄底成功”。
改用同样预登记的12个月盈利延迟，则只有三个不同买点，年化中位数-0.19%、
最差回撤-53.84%、期末本金亏损19/34。这种口径敏感性不符合稳健操作规则的要求。

40%阈值、延迟6月的34个满期账户也只有三个实际买点，其中19个资金起点都等到2001-04-02。
按资金起点与按买点等权回答的是两个问题，全部逐行结果和按买点等权汇总均保留，未挑最漂亮的汇总口径。

标普价格历史已由原FRED约10年扩展为Cboe自1975-01-02的日线，研究统一截止2026-10-19。
Cboe原始CSV及其图表JSON共13,059条收盘一致；与FRED重叠2,512日，有30日报价不同，全部保留。
v1固定来源敏感性共9,933账户、15,360配对行：入场日期及满期状态均未变化，
最大期末财富差17.13美元，最大入场后年化差约0.000597个百分点。这是日历修正前的来源检验，
不代表所有早期价格均已被独立证明。

进一步的交易日历审查查出：标普1985-09-27、纳指1998-07-03/2001-01-01/2019-04-19有休市报价。
v2剔除上述观测；标普1999-12-31缺价依据花旗SEC披露中的S&P年末收盘1469.25补入。

例如无条件分批的31个纳指十年窗口中，11个触及该缺口；余下20个窗口仍有-75.95%的最差回撤，
但期末本金亏损数变成0。直接丢掉受影响窗口会掩盖一部分关键坏情景，补齐原始报价仍是待办。

来源及许可正文见[数据审查](DATA_SOURCES.md)。Cboe公开下载不等于无限期留存或再分发许可；

## 为何“低买高卖”直觉与这些结果可以同时成立

1. **分位高不等于已有利润。** PE=价格/盈利。盈利下降时，即使价格下跌，PE仍可能上升。
   本实验的80%估值退出没有“先盈利”的条件，准确名称是估值退出，不能把所有卖出叫作止盈。
   例如2000-01-03开始积累、延迟12月估值组2001-03-22首次买入，2002-11-01、12-02、2003-01-02
   的三次估值卖出，相对含费用的平均购入成本分别亏损约5,275.54、4,448.25、5,076.66美元。
   这是逐笔账本的解释性反例，不是税务成本计算；同一起点的6/12月两组全部卖出均另存诊断表。
2. **低于高点不等于低于开始等待时的价格。** 例如100涨到200再跌至140，已经跌30%，
   仍比最初贵40%。真正比较应包含等待现金，以及卖出后何时、按什么规则重新买入。
3. **短期企稳不保证下一轮下跌结束。** 五日不创新低、收盘回到十日均线，是当时可算的状态，
   并不是历史最低点或杠杆已经出清的证明。十年持有期还可能遇到下一轮独立熊市。
4. **买入后的收益与整个计划的收益不同。** 等多年以后才开始一个不错的十年持有期，
   可能仍落后于同一批资金较早投资。当前等待现金按零利息处理，有息现金管理需另作明确情景，不能外推为所有现金工具的机会成本。
5. **退出可能有风险收益取舍。** 降低回撤有价值，但卖掉后错过上涨和回补失败也有成本。
   某组退出改善回撤或本金亏损，不等于它对所有指数、阶段和资金安排都有优势。

“低估”在此只是相对自身历史的PE代理，不是对企业真实价值的完整估计；
6/12个月盈利延迟也不能消除Shiller插值、修订和历史公开时间的不确定性。
