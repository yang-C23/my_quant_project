## 先回答投资问题

“估值有吸引力—抛售压力—压力减弱/价格企稳—分批投入”已经拆成独立、可复算的阶段，
进入真实现金账本。每月收入先进入现金池，不要求每月买股票。
普通定投、无条件分批、立即接恐慌、等待企稳、等待波动/杠杆代理下降、保留底仓和分批退出，
使用相同的外部入金日期、金额和成本比较。

目前证据不支持把“跌得够深”当作能够控制未来十年回撤的充分条件。
好的第一次入场之后，仓位仍可能经历下一次完整熊市；没有退出或持续风险约束时，
仅优化第一次买入日不能给账户提供长期回撤上限。
本轮纯价格版本在事件确认后启动12批月度预算，后续不会因再次下跌自动停止；
估值联合版本则持续要求低于买入分位。两种执行语义分开保存，
不能把前者的结果说成“每一批都重新确认已经企稳”。
反过来，回撤很小也可能来自长期不买入，必须同时检查期末财富、现金占比和等待成本。

所有金融结果属于**已见历史上的探索**，尚未晋级为实盘规则。
本轮已观察过全部历史，再把时间段标为“训练/验证/测试”，不能重新创造未见样本。
主实验滚动五年和十年窗口按年平移；三个已核对公司行动的ETF另增加全部可用月度起点，
共668个账户。窗口互相重叠，亏损窗口比例不是独立的胜率。
本轮没有购买数据、交易或发送外部交易提醒。

## 企稳等20、60还是120个交易日

追加研究冻结15项规则，完成3,660个账户、15项资料不足暂停。
与主研究重合的1,708个账户核验一致；三个期限使用同样事件定义和资金账本，
60/120日版本只延长事件确认期限，不事后回填原20日版本。

纳斯达克2008-09-05的压力事件，20日版本到期未确认；

## 回撤为什么仍可能超过50%

问题并不只在“第一笔买早了”。例如沪深300十年企稳账户在2018-08-14开始买入，
后来仍从2021年的账户高点经历约42.54%回撤，直到样本结束最大回撤区间尚未恢复。
中证500的同规则十年账户从2021-09-13高点跌至2024-02-05低点，
直到2026-01-06才恢复，经历1,042个交易日。

纳斯达克完整价格历史中，无条件现金池及企稳买入后长期持有的最大回撤都在约82%。
2000年高点之后的长期下跌不能通过“以前某天买得便宜”自动规避。
这份早期历史是指数研究，不表示1986年就存在今天的可投资ETF。

另一方面，沪深300最近五年的KDJ现金池回撤只有5.68%，
但平均81.50%的财富在现金中，年化仅0.45%。
这不是已经证明J指标识别了强平底部。保留50%底仓也不构成仓位上限：
它只是入金分配比例，股票上涨后权重可以大幅超过50%。

最近五年企稳账户低于累计入金的最长持续期，标普为45天、纳斯达克78天、沪深300为528天。
但扩展到全部登记窗口，纳斯达克最长达到3,307天，沪深300达到1,226天；
“可以接受初期一两年亏损”不能被转换为这些策略会在两年内回本的承诺。

沪深300的最近十年改善值得保留，但全部11个十年窗口中，
退出版最差年化仅0.17%，最差回撤44.46%，相对无条件现金池的最差财富差为−35,785.83。

显示回到旧高点就卖出可能过早结束上涨行情。
纳斯达克最近十年的退出版平均85.22%财富在现金中，期末341,502.07，
显著低于无条件现金池的871,625.96；其完整历史仍出现约74.39%的回撤。
因此不能把最近十年的10.76%回撤当作这一退出规则的普遍风险上限。
创业板六个十年窗口中，退出版最差年化−3.03%、最差回撤50.59%，
财富差中位数为−57,959.55；降低部分回撤并不意味着更适合长期复利。

3/6/12批也没有统一赢家。例如最近五年，沪深300企稳后分3/6/12批的年化为
−1.19%/−0.65%/0.56%，较慢投入减轻了继续下跌的影响；
纳斯达克最近十年对应15.79%/15.24%/14.61%，较快投入减少了上涨阶段的闲置现金。
这些是同一触发下的预算比较，不能用事后选出的最优批数构造一条从未实际登记的策略。
月供比例、事件加仓和成本敏感性保留全部配置与结果。

多数条件只是减少入场或增加现金，没有显示跨市场稳定的额外收益。

期限/季节控制后的贴水仍缺当时预期分红，不能称为完全校正后的无套利基差。

[`cash_pool_extensions.yaml`](../../configs/cash_pool_extensions.yaml)及登记副本为准：

| 一手序列 | 压力与减弱的可复算定义 | 主要局限 |
|---|---|---|
| Cboe VXN、SKEW、总Put/Call | 过去5年分位达到90%，之后降至70%以下，并满足价格企稳 | 分别代表不同风险；不是资金持仓或强平记录；Put/Call方法变更处重新预热 |
| 上交所融资余额 | 低于过去252日最高值至少10%；五日余额变化率不再比前一日更差，并满足企稳 | 仅上交所汇总，不是该指数投资者的杠杆率 |
| FINRA月度融资余额 | 距过去12月高点下降至少10%，当月变化率不弱于上月 | 发布日使用保守假设，美国汇总不能解释单个指数的强平 |
| CFTC杠杆基金持仓 | 已对齐的杠杆基金多头占总未平仓量比例，过去5年分位低于40%，并满足企稳 | 不含全部投资者，发布停摆与历史修订显著影响结果 |
| 中金所期货贴水 | 邻近到期合约内插为30日；与此前3年同季节前后45日比较，负基差分位≤10%，随后≥30%且企稳 | 排除无可靠到期日/不同收盘时点；没有当时预期分红和完整持有成本 |
| 中金所深虚值看跌活动 | 剩余7—45日、交易所Delta绝对值0.05—0.15的看跌期权权利金成交额占比，过去2年分位≥90%后降至≤70%且企稳 | Delta及有效成交额覆盖均需≥95%；这是活动占比，不是期权报价暴涨或净Gamma |

扩展日频因子分别延迟1/2个目标市场交易日进入决策，再下一交易日成交，
过期超过7个自然日不继续使用；固定滞后只是可重复的假设，不替代逐条历史发布时间。
主实验VIX采用另一条已登记规则：高历史分位后回落到事件已观测峰值的80%，
不能将其与扩展VXN的“90%→70%分位”混称为同一个指标。

按危机簇而非每日信号统计，默认五日企稳也没有稳定提高事件后的长期价格回报：
纳斯达克确认事件的买入价中位数比立即入场高约4.2%，
其中最差的一次确认后252交易日最大不利价格变化约−67.4%。
这项事件统计不含现金分批与费用，也不能直接代替账户收益。
少数危机不足以确定精确胜率；全部未确认、资料不足和未来持有期尚未结束的事件均保留。

## 账户和阶段如何量化

每个市场使用本币本金 100,000、每月新增 1,000；
另有月供 500/2,000、批次数、底仓和交易成本的预登记敏感性。
等待现金基础收益为零；指数价格不含股息，不能冒充实际 ETF 全收益。
成交使用前一交易日已形成的信号，在下一可交易收盘价执行，基准佣金 3bp、滑点 5bp；
实际 ETF 另处理交易单位、分红支付、拆分和停牌。

| 阶段 | 本轮定义 | 不能据此声称的内容 |
|---|---|---|
| 估值有吸引力 | 指数自身历史分位低于40%；5年、10年和扩展窗口分开；20/30/50%邻域另列 | 亏损、缺失或过期盈利不是低估；没有完整历史的A股PE/PB继续暂停 |
| 抛售压力 | 距过去252交易日高点至少跌20%，且5日收益低于事先60日波动折算的负2倍标准差 | 这是价格压力，不是已观测到的强平或全部杠杆出清 |
| 价格企稳 | 压力事件后20交易日内，至少连续5日不创新低，且收盘站上10日均线 | 确认之后仍可再次下跌 |
| 波动减弱 | 在企稳条件上加入5日波动降至事件后已观察峰值的80%以下 | 不能使用事件结束后才知道的完整波动峰值 |
| 杠杆/期权扩展 | CFTC、FINRA、交易所融资、VIX/VXN、SKEW、Put/Call、期限控制后的期货贴水、固定Delta深虚值期权活动逐项加入 | 汇总融资不是该指数的杠杆，期权成交/OI不是净Gamma或实际爆仓 |
| 分批买入 | 触发后将可用现金C分成剩余r批，每次使用C/r；月供和卖出净额纳入后续预算 | 不借用未来月供，也不因新月供到账而强制买入 |
| 分批卖出 | 估值80%后分3个合格月份，或80/90/95%分层；技术回到事件前高点退出为另一实验 | “回到旧高点”不等于“估值昂贵” |

实际登记的估值退出在月度执行日依据上一交易日的分位判定并锁定待退出份额；
两个月度执行点之间短暂触及高估区，不自动产生交易。没有将月末已知信息倒填为月中成交。
估值与压力联合时，压力出现当天及确认买入时均要求低估；不倒填确认日才出现的低估。
没有估值资料的价格实验单独标明，不能冠以“低估入场策略”名称。
等待6/12/24个月只用于衡量现金和机会成本，不是自动强制入场期限。

旧名称的含义：

- `dca`：Dollar-Cost Averaging，按固定时间和金额分批买入；旧版本是初始本金分12期加当月新增款。
- `kdj`：旧版本只在月度执行日满足 `J<0` 时买入；它是短期价格指标，不是估值指标。
- `kdj_core50`：50%的初始/新增资金进入长期持有部分，另50%按KDJ择时。
- 新 `pool_*`：保存所有累计现金，按本轮预算逐批使用，修复旧择时规则可能长期遗留暂停期间月供的问题。
- `core50` 是**入金分配比例**，并非每天把股票仓位维持为50%，更不是50%的回撤保险。
- “宽基50%＋红利低波50%年度再平衡”是另一个组合维度，与底仓比例无关。

## 怎样看收益和回本时间

报告年化采用剔除外部入金后的时间加权复利；XIRR另表展示资金加权结果。
期末财富包含待投现金、股票及应收分红，不把持续存钱记为投资收益。
分红在除息日产生应收款，支付后才能买入；不在调整收益上再加一次现金分红。

“回本”分为两项：

1. 账户财富低于累计入金的持续时间，回答投入的本金何时不再亏损。
2. 时间加权净值低于前期高点的持续时间，回答历史浮盈何时恢复。

尚未恢复的区间标为截至样本终点的下界，不将其伪装成已经实现的回本天数。
一直等待而没有买入的账户标明“未入场”，不会把零亏损天数计作选时成功。

## 估值实验为什么分成两个版本

作者维护的[Shiller数据](https://shillerdata.com/)已更新至2026年9月；
盈利有效观测较晚只到2026年6月。旧的2023年版本保留，不能用过期值继续计算“今日低估”。
这份数据含插值及历史修订，不是完整的当时可得盈利档案。

第一组将整个月度PE延迟6/12个月后使用，保留全部52项原登记规则。
第二组单独登记60项“当天指数收盘价÷假设已知的滞后盈利”，
并用相同盈利滞后规则构造历史月度PE参考分布。
第二组会及时反映价格下跌，但仍然受到盈利修订、假设发布日期、月均参考价与日收盘价差别的限制。
这组是在发现旧口径的价格也被滞后之后追加的公式审查，不冒称最初预登记或未见样本。

两种公式不能混为一个“PE策略”。采用5年、10年或扩展历史窗口，
有时会决定到底能否入场；没有证据把收益最高的那个窗口直接封为长期“甜点”。

## 针对5—10年积累财富的具体结论

本轮可以否定若干过强假设，尚不能发出今天应该买入或卖出的指令。
“低估＋恐慌＋企稳”适合作为可解释的候选研究框架，
但现有结果不支持把所有现金长期押在这一种罕见触发上，
也不支持依靠它保证30%以内回撤或两年内回本。

| 标的/风格 | 本轮证据支持的处理 | 晋级实际操作前最需要补的证据 |
|---|---|---|
| 标普500 | 保留普通分批、DCA及部分底仓为主要对照；不因最近五年抄底较好就全部改为纯择时；回到旧高点退出有明显踏空代价 | 十年以上同口径日线/全收益、真实ETF或QDII执行、历史盈利可得性 |
| 纳斯达克100 | 长期上涨与极深历史回撤同时存在；纯等待策略有长期空仓失效，底仓可以降低部分等待成本但不能封住回撤 | 实际ETF总回报、渠道成本；确认期限敏感性不能当成新的未见验证 |
| 沪深300、上证50 | 保留“事件入场＋分批退出”候选；最近窗口改善不足以宣布达到长期风险目标 | 长期PE/PB和发布日、含股息ETF同窗口验证；价格退出与估值退出分别比较 |
| 中证500 | 企稳/退出可减轻部分区间回撤，但十年窗口的财富优势不一致，不能只展示最近十年 | 全收益与实际ETF、更多危机阶段、明确持仓后的风险约束 |
| 中证1000、创业板指、科创50 | 当前测试仍有很深回撤，不能仅凭弹性大就作为稳定复利的主要依据 | 更完整风格周期和可投资数据；科创50目前只有一个完整五年窗口 |
| 科创100 | 继续保留短历史观察，不发布五年十年年化结论 | 真实历史自然积累；不能用回溯或别的指数补足 |
| 512890、515100 | 分别保留无条件分批、分红处理及宽基组合；不统一等待20%恐慌。当前五年案例优于纯等待，但样本少且行业风险不同 | 历史成分、分红削减、利率/行业归因和更长实投周期 |
| SPHD | 本轮不排序、不推荐其具体交易规则 | 允许长期研究使用的实际价格与完整公司行动历史 |

执行研究时，现金池继续采用“到账后才能使用、信号后下一可交易时点、每批C/r、
卖出锁定份额、缺数据暂停”的可审计规则。6/12/24个月是等待成本的复核点，
不是未经检验的强制买入日期。若未来选择保留底仓，应明确它是资金分配而非固定风险上限；
若未来增加趋势或波动仓位约束，应作为独立新实验，不能回填到本轮结果中。

未来执行建议必须绑定具体投资渠道、真实费用/税务、可用现金和已验收数据版本。
目前日常入口保留影子观察和暂停原因；本轮历史回测不能替代20个真实交易日的影子验收。
