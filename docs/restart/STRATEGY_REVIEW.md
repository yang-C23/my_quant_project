## 2. 名称对应的实际代码行为

| 名称 | 已实现规则 | 容易误解的地方 |
|---|---|---|
| `dca` | Dollar-Cost Averaging，定期定额投入；本金12期，每月投入当月新月供，持有不主动卖出 | DCA并不要求美元。这里是基准，不表示用户必须永久定投 |
| `kdj` | 每个月度执行日，前一交易日J<0才投入一份本金和当月月供；否则暂停 | 不是J<0每天立即买；没有PE/PB过滤，没有去杠杆或企稳判断，也没有J回升就卖的退出 |
| `kdj_core50` | 初始本金和之后月供各分一半；底仓本金立即投入、底仓月供持续买入，另一半按上述KDJ规则 | 不是始终半仓，也不是50%永远保留现金；两部分市值比例会漂移，当前没有按50%定期再平衡 |
| `dca_core50` | 本次新加的比较对照：一半立即投入并持续买入，一半本金分12期加持续月供 | 用于将“底仓初始买得更早”的影响与KDJ过滤区别开，不是新增推荐 |

KDJ为9日RSV、K/D各1/3平滑、初始50、J=3K−2D。
J<0表示该动量公式下的超卖，不表示盈利/净资产估值便宜，更不能证明强平已经结束。

美国当前参考源只有close，缺真实high/low，所以两项KDJ实验暂停。
A股同一标的跑了各版本，原摘要混合列示容易误以为逐市场事后选择了不同策略。
新复核完整保留31组结果，另有4项美国KDJ/底仓KDJ因缺OHLC暂停。

## 3. 现金规则是实质性的研究缺口

`engine.py`当前月度投入为“剩余本金批次额度＋当月月供”，
只有估值策略发生退出后重返低估才重划现金预算。
纯KDJ从不退出，停投月份累积的钱没有一般性的重新纳入预算机制。
这些钱仍在现金和账户权益中，并未丢失；但它们不能按用户现在希望的方式重新分批投入。

本次共同窗口的沪深300：

|---|---:|---:|---:|---:|
| DCA | 1.78% | -45.61% | 4.00% | 0.04 |
| KDJ | 0.18% | -15.32% | 77.82% | 145,333.36 |
| KDJ＋50%底仓 | 1.30% | -33.48% | 36.39% | 72,666.64 |
| DCA＋50%底仓 | 2.05% | -45.61% | 1.98% | 0.00 |

KDJ期末现金中约33,333.33仍属未投本金预算，约112,000.03在该预算之外，
主要是停投月份累积的月供及分钱尾差。
因此不能把低回撤都算成成功选时，也不能据此否定所有KDJ或现金池择时方法。

## 4. 为什么“等带血筹码”不能仅靠最大回撤判定

最大回撤衡量历史净值高点到后来低点的跌幅。无入金例子：
100涨到300，再跌到150，最大回撤是50%，相对最初本金仍盈利50%。
这与“刚买入就亏50%”是两个不同问题。

一个指数从100跌到80后买入，如果随后到50，入场后仍会亏37.5%。
下跌已经很深不等于未来下跌空间很小。另一方面，等待充分确认可能错过最初的大幅反弹。
两者的代价都必须计算，不能只保留成功等到底的事件。

下一轮分别报告账户高点回撤、每笔入场后20/60/252日最大不利变动、
相对累计投入的浮亏、回本与恢复时间、5/10年最差窗口和等待成本。
“可接受前1—2年浮亏”不能自动推导出“系统会在2年内恢复”。
