# 宽基与红利低波研究协议

本文件定义实现语义；全部研究范围保留在[总计划](MASTER_PLAN.md)。
原基线参数保存在`configs/longterm.yaml`；当前现金池研究使用`configs/cash_pool.yaml`，
组合与衍生品增量实验使用`configs/cash_pool_extensions.yaml`。每次先写`registration.json`，再计算结果。
任何结论都必须指明代码指纹、数据快照、来源版本、价格口径和证据等级。

## 账户与时间

各市场本币示例本金100,000，起始月份之后，每个月首个交易日新增1,000。
本金默认12份；基准包括立即投入本金和12期投入本金，两者继续接受相同月供。
等待现金一直计入权益，基准现金收益0；2%等常数只用于敏感性，不声称真实可获得。
初始预算、月供比、费用和股息税可配置，用户实际账户必须单独对账。

信号由前一个已完成交易日的数据生成。旧引擎按原登记使用下一开盘或收盘；
当前现金池跨市场统一按下一可交易日收盘成交并扣滑点，真实ETF亦如此。
收盘代理不代表按收盘价必然成交；停牌不成交、不消耗批次。
未成交不消耗资金，不借未来月供、不使用杠杆；交易单位、滑点、佣金和现金约束同时生效。
券商实际最低佣金、账户税务及QDII折溢价需另行确认；现有探索不扣基金净值已包含的管理费。

原价与公司行动分开。除息前份额形成应收；支付日收盘后记入现金，下一可交易时点才用于买入。
周末到账在下一交易日开盘前可用。分红现金展示留在账户中且不用于买入；再投资版本按策略资格使用。
股息税从权益扣除；拆分只改变份额。供给复权价时禁止再附加股息事件。

年报披露净值增长率还需单独核对。证监会编报规则第1号第八条的分红后参考净值为
“除息前一交易日NAV减每份分红”；本平台经济总回报信号使用`(当日价格+应收分红)/前日价格`，
真实账户则按支付日可用现金处理。三者分别命名、保存，不能为了拟合年报改现金账本。
[披露公式原文](https://neris.csrc.gov.cn/falvfagui/rdqsHeader/mainbody?navbarId=2&secFutrsLawId=3acb98d2b17745a19ebb5afbcc52b583)

ETF正式选择必须使用完整历史产品名录：当时已上市至少60个交易日、跟踪同一指数、非杠杆，
以之前60交易日成交额排序。固定候选ETF的价格诊断不代表已执行这一无幸存者偏差规则。

## 估值与资金状态

温度统一为0便宜、1昂贵。PE/PB必须为正；负盈利、缺失或未验证口径不视作极低估。
PE主窗口10年，5年与10年预热后的扩展窗口分别登记。
只比较当前值与严格早于当前日期的历史值：

```text
百分位 = (过去有效值中小于当前值的个数 + 0.5×等于当前值的个数) / 有效观测数
```

窗口要求完整日历年跨度与至少`0.8×252×年数`个有效日频观测。月频Shiller不能直接满足日频契约。
先按`available_at`对齐决策时点，选当时已知的最新经济日期，再算分位；较早日期的延迟修订不能替代较新观测。
经济日期不是发布时间。估值超过7日未更新则不向前填。
正式对比只选所有参与策略都已预热的相同账户窗口；没有预热的窗口给出暂停记录。

PE分位<40%才允许月度预算买入；40%≤分位<80%暂停新增投入；≥80%执行独立退出实验。
当前现金池将所有已到账本金、月供和可再投资分红统一管理。信号触发新周期时设剩余批数R=12，
每个合格月投入当时可用现金C/R，再将R减一。暂停期间只入金、不买入；恢复时以最新C和剩余R重算，
因此过去月供不会遗留在策略永远无法使用的现金中。R耗尽后，新现金等待下一次合格周期；
无条件基准可在下一月份启动新周期。额外事件投入消耗预先登记的额外批次，不能动用未来月供。
新周期的3/6/12批、不同事件批数及月供比例分别登记，未根据完整历史挑最佳值。

`legacy_*`实验继续使用旧规则：本金固定份额加当月月供，暂停月供可能长时间留存。
这是被审计的对照，不能与新现金池混用名称或覆盖原报告。

时间退出：高估时锁定份额，在三个符合高估条件的月度执行日累计卖出1/3、2/3、全部。
分层退出：80%、90%、95%对应本轮锁定份额的累计1/3、2/3、全部。
拆分同步调整锁定份额；不足交易单位的剩余份额在最终清仓处理。
底仓实验使用独立的50%持有子账本与50%择时子账本，只出售择时部分；费用按各子账本订单计。
底仓的50%本金在起点投入，之后持续投入每月月供的一半。

PB使用同向分位；股息率、盈利收益率及其相对国债收益率之差使用反向分位。
指数估值不能用成分PE算术平均替代。自算需要历史成分、计算用股本、当时可得财报及明确亏损处理。
缺少这些输入时，不从当前成分重建过去“低估”。

## 恐慌、企稳、KDJ和扩展

恐慌同时满足：距过去252交易日最高收盘回撤至少20%，且5日收益≤−2×此前60日收益标准差×√5。
当前主版本60日波动率整体滞后5个交易日，排除整个五日冲击区间；
旧版本滞后1日，作为独立邻域实验保留。连续恐慌至少20日没有新恐慌后才另计事件。
立即入场在事件次日；企稳在事件后20日内，连续5日不创事件以来最低收盘且收盘>SMA10，再次日成交。
统一使用收盘确认，不以A股日内低点对比仅有收盘的美国指数。
压力减弱版本另要求最近5日波动率不超过事件以来已知最高值的80%。
事件额外使用两份剩余本金预算，实际现金不足则缩减，20交易日内最多一次。
默认仍需低估条件；缺估值时不将纯价格恐慌结果冒充联合策略。

KDJ使用9日RSV，K、D以50为种子递归1/3平滑，J=3K−2D；无高低价不能计算真正KDJ。
`J<0`独立实验及与低估联合实验分开。KDJ版本在月度执行日使用上一交易日J判断当月投入资格。
`legacy_kdj`采用12期本金和当月月供，`pool_kdj_*`采用所有到账现金C/剩余批数R；
两种结果只适用于各自登记的资金规则和月度频率。

VIX、融资收缩、基差、偏斜、OTM、0DTE与Gamma逐项登记。基差校正期限、无风险利率、股息与换月；
`gamma_scenario`必须显式提供假定做市商方向，输出是情景估计，非实际净Gamma或爆仓证据。
OI、成交量、ETF份额申赎、ICI汇总流量、CFTC持仓分别保留统计含义。

## 红利低波与组合

H30269与930955分别研究，SPHD作美国对照。指数发布前回溯、发布后历史和ETF上市后的可投资记录分开。
账户中的分红贡献指ETF向持有人的现金分配；基金份额价格还包含其内部保留的股票股息。
512890没有向持有人现金分红，不等于底层股票没有股息。现有`price_profit_net_costs`列
只是账户利润扣除ETF现金分红净额，不能据此拆出底层股票的纯价格贡献。
当前固定宽基/红利低波组合将每笔现金批次等分投入两只基金，年度再平衡目标由前一交易日持仓和价格确定，
先按当日已核实公司行动调整前收盘，再于当日收盘成交。停牌顺延；
再平衡只动用已释放批次及卖出所得，不提前动用等待中的预算。
另登记不再平衡与现金分红对照。没有每日维持固定50%权重的隐含交易。
组合与底仓维度相互独立，不将两个50:50概念混合。

必须补齐分红再投资/现金分红、行业集中、分红削减、利率敏感性、跟踪差、费用、落后成长的持续期分析。
未取得历史分红支付日、成分和行业权重时，明确暂停这些归因；价格结果不能为高股息风格下结论。
科创100、科创50及短历史基金不补造10年或15年可投资业绩。

## 绩效公式

每次入金前按执行时点价格估值。设前收盘权益E、当次入金前权益B、外部入金C、当日最终权益V：

```text
日TWR因子 = (B/E) × (V/(B+C))
首日因子  = V/C
累计TWR   = 各日因子连乘 − 1
年化TWR   = (1+累计TWR)^(365.2425/实际日数) − 1
回撤      = TWR净值 / 包括初始1在内的历史最高净值 − 1
```

这能区分跨夜涨跌与开盘入金，不能用`V/(E+C)`把新资金混入已经发生的隔夜收益。
XIRR使用真实日期的负贡献与期末正权益；异常多次正负切换可能多根时不擅自选根。
记录累计投入、期末财富、现金及占比、佣金、滑点、税、分红、全期间换手、回撤及最长未恢复交易日数。
相同窗口与资金计划才计算相对DCA期末财富差；收益和复利不用简单相加。

当前固定规则不拟合参数，滚动测试不冒称完成数据驱动优化。重叠10/15年窗口只作描述性稳定性分析。
全部结果、失败、暂停及参数邻域留存；最终留出不再反复调参选冠军。
仅在验证和最终样本外都有稳定证据时晋级，优先简单低换手规则。约30%回撤是目标而非保证。

当前正式研究受数据准入约束；`--exploratory`只准许明确标注的指数价格代理诊断。

## 衍生品、融资与币种扩展的限定

- 期货使用相邻到期合约内插30日价格，不按事后主力合约拼接，不外推；
  只用2016年后现货/期货收盘可比区间。第三周五不在独立冻结的交易日历中则排除该到期合约。
  过去3年相近日历季节的基差分位用于探索；缺少当时预期分红，不能声称已完成理论持有成本校正。
- 期权按剩余7—45日、报告Delta绝对值5%—15%统计Put/Call权利金成交额占比。
  成交额按万元换算，并检查隐含成交均价是否在高低价范围内。缺Delta或异常交易金额超过5%的日子不生成占比。
  只有日终月度到期统计，没有美国日内0DTE、买卖方向或真实做市商净Gamma证据。
- 上交所融资仅代表沪市汇总，FINRA代表美国账户月度汇总；
  CFTC杠杆基金多头/OI不包含所有市场参与者，均不等于被迫平仓量。
- 新取得的日频因子分别假设滞后1/2个市场交易日进入信号，之后还需下一交易日执行。
  这是探索性延迟情景，不伪造实际历史公布时间。缺失的新观测不能沿用较早的非空字段。
- 汇率实验将美国价格指数换为人民币计价，并暂停使用超过7日旧汇率的新交易。
  持仓估值可沿用最后一条汇率，过期日数单列。美联储H.10的日汇率按周发布，
  通常星期一16:15发布上周记录，历史归档不随修订覆盖；
  登记中的日频可得时间并非核实后的H.10发布时间，本组不能视为可执行的历史外汇报价。
  0/2/5/10%初始溢价一年线性消退仅为渠道敏感性，不是真实QDII历史。
  后续使用不可修订的逐周档案核查发布时点，并另取得与ETF成交时点匹配的市场汇率后才能晋级。
  [美联储H.10发布说明](https://www.federalreserve.gov/releases/h10/about.htm)
- 事件分析另按120日内连续压力事件归并危机簇；少于3簇不给数值置信区间。
  未确认但资料完整的事件计等待现金，缺因子和未来观察不足保留缺失。所有策略均从同一事件日比较。
