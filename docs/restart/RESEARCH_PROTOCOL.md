# 宽基与红利低波研究协议

本文件定义实现语义；全部研究范围保留在[总计划](MASTER_PLAN.md)。
参数及实验清单来自`configs/longterm.yaml`，每次执行先写`registration.json`，再计算结果。
任何结论都必须指明代码指纹、数据快照、来源版本、价格口径和证据等级。

## 账户与时间

各市场本币示例本金100,000，起始月份之后，每个月首个交易日新增1,000。
本金默认12份；基准包括立即投入本金和12期投入本金，两者继续接受相同月供。
等待现金一直计入权益，基准现金收益0；2%等常数只用于敏感性，不声称真实可获得。
初始预算、月供比、费用和股息税可配置，用户实际账户必须单独对账。

信号由前一个已完成交易日的数据生成；最早下一交易日开盘成交。只有收盘价的数据
采用明确标注的`next_close`价格代理，不能冒充ETF开盘成交。
未成交不消耗资金，不借未来月供、不使用杠杆；交易单位、滑点、佣金和现金约束同时生效。
券商实际最低佣金、账户税务及QDII折溢价需另行确认；现有探索不扣基金净值已包含的管理费。

原价与公司行动分开。除息前份额形成应收；支付日收盘后记入现金，下一可交易时点才用于买入。
周末到账在下一交易日开盘前可用。分红现金展示留在账户中且不用于买入；再投资版本按策略资格使用。
股息税从权益扣除；拆分只改变份额。供给复权价时禁止再附加股息事件。

ETF正式选择必须使用完整历史产品名录：当时已上市至少60个交易日、跟踪同一指数、非杠杆，
以之前60交易日成交额排序。固定候选ETF的价格诊断不代表已执行这一无幸存者偏差规则。

## 估值与资金状态

温度统一为0便宜、1昂贵。PE/PB必须为正；负盈利、缺失或未验证口径不视作极低估。
PE主窗口10年，5年与10年预热后的扩展窗口分别登记。
只比较当前值与严格早于当前日期的历史值：

```text
百分位 = (过去有效值中小于当前值的个数 + 0.5×等于当前值的个数) / 有效观测数
```

窗口要求完整日历年跨度与至少`0.8×252×年数`个有效日频观测。月频Shiller不能直接满足日频契约。
先按`available_at`对齐决策时点，再算分位；经济日期不是发布时间。估值超过7日未更新则不向前填。
正式对比只选所有参与策略都已预热的相同账户窗口；没有预热的窗口给出暂停记录。

PE分位<40%才允许月度预算买入；40%≤分位<80%暂停新增投入；≥80%执行独立退出实验。
首次低估时本金预算分12份，合格月份使用一份及当月到账的月供。暂停月供留在现金账户，
恢复时只使用当前月供，不自动补扣过去月份；积累月供在下一轮重划预算时才纳入分期。减仓后再次低估，剩余可用现金按新周期分12份。

时间退出：高估时锁定份额，在三个符合高估条件的月度执行日累计卖出1/3、2/3、全部。
分层退出：80%、90%、95%对应本轮锁定份额的累计1/3、2/3、全部。
拆分同步调整锁定份额；不足交易单位的剩余份额在最终清仓处理。
底仓实验使用独立的50%持有子账本与50%择时子账本，只出售择时部分；费用按各子账本订单计。

PB使用同向分位；股息率、盈利收益率及其相对国债收益率之差使用反向分位。
指数估值不能用成分PE算术平均替代。自算需要历史成分、计算用股本、当时可得财报及明确亏损处理。
缺少这些输入时，不从当前成分重建过去“低估”。

## 恐慌、企稳、KDJ和扩展

恐慌同时满足：距过去252交易日最高收盘回撤至少20%，且5日收益≤−2×此前60日收益标准差×√5。
60日波动率不包含触发当日收益。连续恐慌归为同一簇，至少20日没有新恐慌后才另计事件。
立即入场在事件次日；企稳在事件后20日内，连续5日不创事件以来新低且收盘>SMA10，再次日成交。
事件额外使用两份剩余本金预算，实际现金不足则缩减，20交易日内最多一次。
默认仍需低估条件；缺估值时不将纯价格恐慌结果冒充联合策略。

KDJ使用9日RSV，K、D以50为种子递归1/3平滑，J=3K−2D；无高低价不能计算真正KDJ。
`J<0`独立实验及与低估联合实验分开。

VIX、融资收缩、基差、偏斜、OTM、0DTE与Gamma逐项登记。基差校正期限、无风险利率、股息与换月；
`gamma_scenario`必须显式提供假定做市商方向，输出是情景估计，非实际净Gamma或爆仓证据。
OI、成交量、ETF份额申赎、ICI汇总流量、CFTC持仓分别保留统计含义。

## 红利低波与组合

H30269与930955分别研究，SPHD作美国对照。指数发布前回溯、发布后历史和ETF上市后的可投资记录分开。
固定宽基/红利低波50:50每年第一个共同交易日再平衡；新资金按目标差额分配，所有成交进入同一现金账本。
组合与底仓维度相互独立，不将两个50:50概念混合。

必须补齐分红再投资/现金分红、行业集中、分红削减、利率敏感性、跟踪差、费用、落后成长的持续期分析。
未取得历史分红支付日、成分和行业权重时，明确暂停这些归因；价格结果不能为高股息风格下结论。
科创100、科创50及短历史基金不补造10年或15年可投资业绩。

## 绩效公式

每次入金前按执行时点价格估值。设前收盘权益E、当次入金前权益B、外部入金C、当日最终权益V：

```text
日TWR因子 = (B/E) × (V/(B+C))
首日因子  = V/C
累计TWR   = 各日因子连乘 − 1
年化TWR   = (1+累计TWR)^(365.2425/实际日数) − 1
回撤      = TWR净值 / 包括初始1在内的历史最高净值 − 1
```

这能区分跨夜涨跌与开盘入金，不能用`V/(E+C)`把新资金混入已经发生的隔夜收益。
XIRR使用真实日期的负贡献与期末正权益；异常多次正负切换可能多根时不擅自选根。
记录累计投入、期末财富、现金及占比、佣金、滑点、税、分红、全期间换手、回撤及最长未恢复交易日数。
相同窗口与资金计划才计算相对DCA期末财富差；收益和复利不用简单相加。

## 验证、选择与发布

固定参数后按50%训练、25%验证、25%最终留出报告；另列5年训练+2年验证后的1年滚动测试。
当前固定规则不拟合参数，滚动测试不冒称完成数据驱动优化。重叠10/15年窗口只作描述性稳定性分析。
全部结果、失败、暂停及参数邻域留存；最终留出不再反复调参选冠军。
仅在验证和最终样本外都有稳定证据时晋级，优先简单低换手规则。约30%回撤是目标而非保证。

当前正式研究受数据准入约束；`--exploratory`只准许明确标注的价格诊断。
没有正式晋级规则、实际账户、可信日历或新鲜数据时，每日输出“暂停评估”，不发送交易建议。
20真实交易日影子运行验证工程可靠性，不能代替长期策略验证。
