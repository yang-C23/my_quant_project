# 投资问题、后续研究与阶段收尾条件

2026-10-21用户已明确授权整理并上传Git，同时要求分析下一阶段值得做的工作。
本页定义收尾边界；实际阶段状态只在任务看板维护，不以机器空闲、运行数量或工程测试通过代替投资问题已经回答。
“值得长期持有”与“不需要止盈、只需要找到入场点”是不同假设，分别核验。
研究对象为标普500和纳斯达克100；宽基及红利低波保留，不把标的写成不存在于本轮登记的纳斯达克1000。

## 本阶段应回答的问题

1. **先收敛现有证据。** 从全部已登记5/10年窗口比较无条件分批、普通DCA、择机后持有、
   50%底仓和分批退出；报告最差/中位/最新窗口、财富差、XIRR、回本时间及等待成本，
   逐一说明低回撤是否只是现金比例高。不得只看最近五年或最佳参数。
2. **区分账户年限与真实持有年限。** 等待两年后才买入的十年账户，只持有约八年。
   下一项事件研究应从实际首次成交起再观察5/10年，未满期单列；
   与同日期普通投入比较，检查第一次入场后是否又遇下一轮熊市。
   这项新检验先冻结事件规则、窗口、成本和全部输出，再运行。
3. **补齐标普历史与可投资性。** 原FRED日线统一预热后不足完整十年账户；
   2026-10-21已取得Cboe自1975年的价格日线，按[实际入场研究协议](ENTRY_HORIZONS_PROTOCOL.md)核验，
   不能将新价格历史等同于已验收的ETF含分红投资记录。
   优先审查发行人/官方来源的长历史与公司行动、使用和留存许可；
   月度Shiller、价格指数和真实ETF分层，不能用月均价伪造每日可成交行情。
4. **明确风险管理与止盈的区别。** 先检验已登记退出规则的收益代价和下跌改善；
   若需要新测试，再单独登记固定风险配置或仓位约束。不能因为分批止盈在上涨阶段落后，
   就推导出任何仓位、任何起点都不需要风险约束。
5. **验证实际渠道与红利低波。** 在数据许可允许的范围内补齐ETF/QDII原价、NAV、折溢价、
   份额、支付日、费用税务和汇率；红利低波关注分红贡献、行业集中及与宽基组合，
   不统一要求20%恐慌，不将短历史外推15年。

免费/已有数据优先。长期PIT估值、完整历史期权链、净Gamma、未来20交易日，
有明确缺口时保留暂停；不能靠反复搜索参数制造最终样本外证据。
历史研究能回答的是已观察到的取舍和失效条件，不是未来收益承诺。

## 何时可以收尾本阶段

- 用户关心的持有/入场/退出问题得到同窗口、含负结果的清晰回答；无法验证的部分明确列出原因。
- 本轮代码、配置、来源、日期、成本、产物与复现入口一一对应；旧修订及失败保留。
- 默认资源入口与skill实际可用，精确回归通过；优化只改变执行效率。
- 形成有限候选及失效条件；没有证据的规则标为不采用或待验证，不需要强行选出冠军。
- 文档、状态、代码整合与发布清单一致，数据和未来影子运行的待办转入下一阶段。

达到这些条件可以封存“探索研究阶段”，不必把研究代码提交与全部实盘准入绑定。
最新问题的定量回答、反例和明确不可验证项见[ETF结果](ETF_TOTAL_RETURN_RESULTS.md)，
完整产物映射见[复现手册](REPRODUCING_ETF_RESEARCH.md)。封存探索不关闭总计划中尚未通过的正式门槛。

## 下一阶段的有限工作

本阶段的主要不确定性已从“能否多算几个参数”转为“真实可投资路径是否成立、
仓位风险是否适合5—10年目标、估值信号是否有足够当时可得的数据”。
优先级按解决这些问题的价值排序，不按哪个实验历史收益最高排序。

| 优先级 | 下一项任务 | 为什么现在值得做 | 明确交付与验收 |
|---|---|---|---|
| P0 | 实际渠道与股票/现金统一账户 | 美元ETF结果不能直接照搬QDII；BIL目前只验证等待阶段 | 境内ETF/QDII为主要情景、海外为对照；接入可核验价格/NAV、汇率、溢价、费用税率情景，完成卖出现金产品→结算→股票买入→分红再用的统一Decimal账本。不能借未来现金，逐笔对账和未来追加检查通过 |
| P0 | 固定风险配置与仓位上限 | 已有SPY/QQQ最差回撤约54%/75%，首次买点没有提供持续回撤约束 | 先登记有限的股票/现金比例及年度再平衡基准，再与现有core50、恐慌分批、机械退出同资金比较；交付5/10年本金亏损、连续回本时间、回撤、财富与等待成本曲线。30%仅为历史筛选目标 |
| P0，可独立推进 | 估值与公司行动补证 | 联合低估企稳没有满5年样本，新增参数无法补齐证据 | 优先纳指自身PE/PB、标普连续历史版本、QQQ早期原始分配与SPHD支付日；逐源给出可得时间/修订/留存/费用/缺口矩阵。成功取得也必须跨源核验；有限探测后仍缺资料则明确不可验证，不无限抓取 |
| P1 | 风格组合与红利低波 | 红利低波样本短，成长与宽基还有持仓/行业重叠 | 同市场固定宽基/红利组合，另列SPY/QQQ重叠暴露；按相同可投资区间比较、分红再投资/现金分红分开，展示行业集中及落后期。不给短基金历史补造10/15年 |
| P1 | 前瞻数据与影子验收 | 已见历史不能重新成为最终样本外 | 固定候选规则版本，持续保存首次获取数据、每日信号与暂停原因；20个真实有效交易日核验稳定性，不回填、不因某日结果不好改参数；正式规则晋级前不产生可执行买卖建议 |
| P1 | 平台维护与恢复 | 本地备份不能覆盖主机故障；旧研究及日历迁移仍有遗留 | 将NDX缺价/美国休市裁定迁入新平台快照并验收，补跨机器恢复演练、明确许可后做异地备份；逐份复核旧成果，不修改冻结研究或自动合并旧工作树 |

第一轮适合做的有限实验包：先完成两资产账本和渠道假设登记，然后测试例如50/70/90%股票配置
（仅是预登记实验点，不是推荐仓位），与100%股票、现有50%入金底仓区分。
年度再平衡的目标比例会随行情漂移，不是每日仓位硬上限；若另测硬上限，必须单独登记触发及成交规则。
先报告无需估值的风险/收益取舍；取得合格估值后才评价择时的额外作用。
BIL之前的历史用零息现金压力基准并单列，不能虚构BIL上市前收益；境内现金产品也只使用真实支持区间。
若存在明确用钱日期，再单独登记到期前逐步降低风险的规则，不能假定所有资金都可以无限持有。

两资产执行必须按历史结算制度和真实账户条件处理。例如美国多数证券交易自2024-05-28
改为T+1，不能把该规则倒填更早历史，也不能不检查现金账户条件就默认卖出当日可再支用。
[SEC结算说明](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins/new-t1-settlement-cycle-what-investors-need-know-investor-bulletin)

估值重建可评估[SEC披露API](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)，
但公司财报还需要历史成分、权重和一致口径，不能单独冒充指数PIT PE。
Gamma/0DTE暂不排第一优先：例如[Cboe日终产品](https://datashop.cboe.com/option-eod-summary)
提供日终和15:45快照、Greeks另选，不能当作完整日内仓位方向或真实强平记录。
先明确字段、粒度、历史区间和许可证，再决定是否值得补充；继续免费优先、不自动购买。

上述工作不要求在封存此次探索前凭空补齐全部免费历史。没有充分证据的买卖规则保持暂停；
不得据已见结果反复改变40%/80%阈值后冒称最终样本外。

## Git交付方式

发布目标为既有公开仓库origin，用户已授权本次上传。推送研究任务分支并建立草稿PR，目标基线v2；
保留冻结提交和全部历史证据，不以研究结果已上传代表策略已经通过正式准入。
主分支合并、数据采购、实盘交易和外部提醒不包含在本次上传动作中。

发布前完成：

1. 把已验证性能实现、默认资源、skill及研究报告整合到同一任务分支，保留原运行的提交映射。
2. 运行全量离线测试、lint、doctor、精确真实回归；只在新改动影响行为时扩大验证。
3. 检查提交范围中的凭据、个人环境、原始行情、授权限制及大文件。仓库保存代码、摘要、
   配置和可共享清单；完整数据/账本保存在DATA_ROOT及合规备份中，不默认上传。
4. 固定最终结论、已知限制和复现说明，再检查远端状态、仓库可见性和分支差异。
5. 在用户明确要求上传后推送目标任务分支、创建PR；记录提交号、验证证据及待办。
